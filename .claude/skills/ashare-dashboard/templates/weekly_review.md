# 周复盘看板规格

## 面向报告

本规格面向 `ashare-weekly-review` 在周日上午(全球主要股市休市)产出的周复盘报告。周度中期视角(ma60/120/250、alpha、ADX、板块周度轮动),围绕用户的持仓股、自选股、关注板块进行上一周的深度复盘,汇总上周国内/全球热点消息,维护宏观环境记忆、清算未结事项、预告下周事件。本周报是下周每个交易日早间推送的起点。

## 看板整体架构

从上到下分区顺序:

1. **顶部窄标题**:看板名 + 周期(如"2026-W26 · 06/22–06/28") + 数据源说明锚点。
2. **HERO 首屏核心结论**:周度定性大字 → KPI 三件套(主力/上涨占比/VIX) → 五指数周涨跌分化条(中心零轴) → 持仓本周速览芯片。
3. **指数周涨跌幅 + 周内节奏**:行式列表(周一→周五收盘对照 + 周涨跌 + 中期均线状态) + 五日节奏迷你时间线(方向 emoji + 关键词)。
4. **资金流向 + 市场情绪(周度)**:周五主力净流出大字 → 中心零轴分流条 → 北向/南向小字 → 涨跌停周度对照。
5. **VIX 恐慌指数周度趋势(定性推断)**:warn 色推断卡(⚠️未取得声明 → 方向推断 → 收敛证据点列 → 与 A 股同步/背离判断)。
6. **指数中期技术面**(周度视角核心):每指数一张卡片(状态横幅 + 指标小格 + 关键位)。
7. **持仓复盘**(中长期持仓栏):每只一个 details,展开体五维明细(本周表现 alpha vs beta / 中期均线趋势体检 / 核心逻辑核实 / 周度对称条件式情景双向 / 结论)。
8. **自选股复盘**:每只一个 details(技术面参考 / 跟踪判断 / 结论)。
9. **关注板块复盘**:rot-card 板块轮动持续性卡片(本周表现 / 持续性 tag / 关联持仓自选)。
10. **短期机会发掘**(独立分栏,蓝色左边框):机会卡片或空态。
11. **未结事项清算**:closure-item 逐条做出明确决定(已解决/转长期跟踪/转下周观察/放弃)。
12. **下周事件预告**:cal-item 日历列表(仅标注不预测)。
13. **下周重点关注**:focus-item 卡片列表(标的 + 关注理由)。
14. **页脚**:数据源说明 + 免责声明。

纪律措辞位预留:
- **对称情景双向 + 参考位"非下单指令"**:第 7 区持仓复盘 04 块。
- **短期机会与中长期持仓分栏**:第 7 区为中长期持仓栏,第 10 区为短期机会独立蓝色左边框分栏。
- **VIX 定性推断标注**:第 5 区 infer-card。
- **下周事件"只标注不预测"**:第 12 区。
- **风险提示与免责**:页脚 disc。

## 模块细节

### ① HERO 首屏核心结论
- **对应数据**:报告"大盘回顾"开篇定性 + 五大指数周涨跌幅 + 主力资金/情绪/VIX 状态 + 持仓本周涨跌。
- **展示形式**:hero-headline 大字定性结论(21px 衬线黑体,关键短语 .up/.down 染色) → kpi-row 三件套(主力净流出 / 上涨占比 / VIX 状态,数字 19px 等宽) → divergeBar 五指数周涨跌分化条(中心零轴,上证/深证/创业/科创/北证,红绿双向) → hold-strip 持仓本周速览芯片(代码 + 周涨跌幅染色)。
- **数据缺失处理**:指数周涨跌缺失 → 分化条隐藏、改显文字"周涨跌数据缺失";主力/情绪/VIX 缺失 → 对应 KPI"—"灰显;持仓缺失 → 隐藏持仓速览条。
- **特殊说明**:分化条用「中心零轴半幅」规则。

### ② 指数周涨跌幅 + 周内节奏
- **对应数据**:报告"指数周涨跌幅"表(指数 / 周一收盘 / 周五收盘 / 周涨跌 / 中期均线状态) + "周内节奏"叙事。
- **展示形式**:idx-row 行式列表(指数名 + 周一收盘 → 周五收盘 + 周涨跌 + 中期均线状态 tag) → rhythm 五日节奏迷你时间线(周一→周五,每日方向 emoji ▲/▼/— + 关键词)。
- **数据缺失处理**:收盘缺失 → 该格"—"灰显;均线状态缺失 → "—";周内节奏缺失 → 隐藏节奏条。

### ③ 资金流向 + 市场情绪(周度)
- **对应数据**:报告"资金流向"(主力/超大单/大单/中单/小单 + 北向/南向周度) + "市场情绪指标"(涨跌停家数周度)。
- **展示形式**:周五主力净流出大字(26px 等宽,跌色) → flow-rows 中心零轴分流条 → flow-note 北向/南向小字 → 涨跌停周度对照(每日涨停/跌停家数小字)。
- **数据缺失处理**:分项缺失 → 该行灰显并标"—";北向不再高频披露 → 保留"不再披露"定性说明不删;情绪缺失 → 隐藏对照块。
- **特殊说明**:**北向资金:实时净流向自 2024 年起不再高频披露**,须如实标注。

### ④ VIX 恐慌指数周度趋势(定性推断)
- **对应数据**:报告"VIX 恐慌指数周度趋势"(方向推断 + 收敛证据 + 与 A 股同步/背离判断)。
- **展示形式**:infer-card warn 色推断卡:⚠️未取得声明 → 方向推断(上行/下行/震荡) → 收敛证据点列(全球 risk-off 证据) → 与 A 股同步/背离判断。
- **数据缺失处理**:VIX 精确值未取得 → 保留"定性推断"标注与依据,**绝不填编造数值**;依据缺失 → 隐藏点列;同步/背离缺失 → 隐藏判断块。
- **特殊说明**:**⚠️ 精确值未取得 · 定性推断**。Wind 不可调用、联网搜索无返回时,基于本周全球 risk-off 收敛证据做方向推断,如实标注非精确读数。

### ⑤ 指数中期技术面(周度视角核心)
- **对应数据**:报告"指数中期技术面"各指数段(vs ma60/120/250 位置 / 均线排列 / ADX / 关键位 / 中期状态定性)。
- **展示形式**:每指数一张 tech-card:tech-head(名称 + 周涨跌) → banner 状态横幅(中期定性) → metric-grid 指标小格(现价 vs MA60/MA120/MA250 / 均线排列 / price_vs_ma250 / ADX) → level-row 关键位 tag。
- **数据缺失处理**:某指标缺失 → 该小格"—"灰显;整只指数技术面缺失 → 卡片降级"本次未提供技术面";中期定性缺失 → 隐藏横幅。
- **特殊说明**:**只定性不预测**。

### ⑥ 持仓复盘(中长期持仓栏)
- **对应数据**:报告"持仓复盘"逐只(本周表现 alpha/beta / 中期均线趋势体检 / 核心逻辑核实 / 周度对称条件式情景双向 / 结论)。
- **展示形式**:每只一个 details:summary = 代码名称 + 本周涨跌 + 结论 tag;展开体 hold-body 五个 dim-block(01本周表现 alpha vs beta / 02中期均线趋势体检 / 03核心逻辑核实 / 04周度对称条件式情景双向 / 05结论)。04 块含 nd-tag"参考位,非下单指令"。
- **分栏**:本块为【中长期持仓】栏,与下方"短期机会"分栏呈现、口径不混用。
- **数据缺失处理**:alpha 缺失(如 ETF) → 显示"ETF不算 alpha"说明;某维度缺失 → 该块灰显"本次未提供"。
- **特殊说明**:04 块含"参考位,非下单指令"nd-tag。

### ⑦ 自选股复盘
- **对应数据**:报告"自选股复盘"逐只(技术面参考 / 跟踪判断是否需要调整 / 结论)。
- **展示形式**:每只一个 details:summary = 代码名称 + 本周涨跌;展开体三个 dim-block(01技术面参考 / 02跟踪判断 / 03结论)。
- **数据缺失处理**:技术面缺失 → 灰显;自选无 → 空态卡片。

### ⑧ 关注板块复盘
- **对应数据**:报告"关注板块复盘"逐板块(本周表现与背景 / 板块周度轮动持续性 / 长期关注理由是否强化或削弱 / 关联持仓与自选)。
- **展示形式**:每板块一张 rot-card:标题 + 持续性 tag(强化/削弱/震荡) + rot-meta(量/价/资金) + 轮动持续性 takeaway + 关联提示。
- **数据缺失处理**:`sector_watchlist.json` 未填写 → 顶部 warn 标注"未填写模板,基于持仓所在板块+宏观 M 类复盘";板块数据缺失 → 对应 meta"—"。
- **特殊说明**:**板块轮动判断只描述"资金过去几周往哪儿走"的客观事实,不预测下周哪个板块会涨。**

### ⑨ 短期机会发掘(独立分栏)
- **对应数据**:报告"短期机会发掘"(标的/催化剂/为何值得注意,或"本周未发掘"+原因)。
- **展示形式**:opp-sec 独立分栏(strength 色左边框);有机会 → opp-card;无 → empty-card 空态卡 + 原因。
- **数据缺失处理**:报告未提供本节 → 整块标"本次未提供短期机会发掘"。
- **特殊说明**:口径与中长期持仓分开,不混用。

### ⑩ 未结事项清算
- **对应数据**:报告"未结事项清算"逐条(事项 / 决定:已解决|转长期跟踪|转下周观察|放弃 / 理由)。
- **展示形式**:每条一张 closure-item:编号 + 标题 + 状态 badge + 理由;状态色码(已解决绿 / 转长期跟踪蓝 / 转下周观察黄 / 放弃灰)。
- **数据缺失处理**:无未结事项 → 空态卡片"本周无积压未结事项";某条决定缺失 → 状态 badge 灰显"待定"。
- **特殊说明**:**逐条做出明确决定,不留"观察中"悬空**。

### ⑪ 下周事件预告
- **对应数据**:报告"下周事件预告"(时间/议题,仅标注待观察)。
- **展示形式**:cal-item 日历列表(日期 + 议题),远期事项单独 cal-far 块。
- **数据缺失处理**:某议题缺失 → 不编造;无远期事项 → 隐藏远期块;整节缺失 → 标"本次未提供"。
- **特殊说明**:**仅标注时间与议题,不预测结果**;这是下周每个交易日 `ashare-morning-brief` 的起点——已知的不确定性清单,不是预测报告。

### ⑫ 下周重点关注
- **对应数据**:报告"下周重点关注的板块/个股"(标的/板块 + 关注理由,来自本周第 3-5 部分发现)。
- **展示形式**:focus-item 卡片列表(标的 + 持仓/自选/板块 tag + 关注理由)。
- **数据缺失处理**:关注理由缺失 → 不编造;整节缺失 → 标"本次未提供"。
- **特殊说明**:**基于本周复盘的具体发现,非泛泛"继续关注市场"**。

### 页脚
- **对应数据**:报告完成时间 + 数据源说明。
- **展示形式**:meta 小字(等宽 11.5px faint) → disc 免责声明。
- **特殊说明**:免责含"VIX 精确值未能从可用专业源取得,为基于全球 risk-off 收敛证据的定性推断"。

## 本看板额外样式与比例条规则

本看板无额外配色或字体(复用共享设计系统)。独有组件类名约定:

- `.hero-headline` / `.kpi-row` / `.divergeBar` / `.diverge-fill`:首屏定性 + KPI 网格 + 五指数周涨跌分化条。
- `.idx-row` / `.rhythm`:指数周涨跌行式列表 + 五日节奏迷你时间线。
- `.flow-rows` / `.flow-note`:资金分流条 + 北向南向小字。
- `.infer-card`:VIX 定性推断卡(warn 色)。
- `.tech-card` / `.metric-grid` / `.level-row`:指数中期技术面卡片。
- `.hold-body` / `.dim-block`:持仓复盘展开体 + 五维明细。
- `.rot-card` / `.rot-meta`:关注板块轮动持续性卡片。
- `.opp-sec` / `.opp-card` / `.empty-card`:短期机会分栏。
- `.closure-item`:未结事项清算条目(状态色码 badge)。
- `.cal-item` / `.cal-far`:下周事件日历列表 + 远期事项块。
- `.focus-item`:下周重点关注卡片。

**比例条规则应用**(规则定义见 SKILL.md「共享设计系统」,此处只标注本看板哪些组件用哪条):

- **五指数周涨跌分化条**(`.divergeBar .diverge-fill`):用「中心零轴半幅」规则。红色向上、绿色向下。
- **资金分流条**(`.flow-rows .fill`):用「中心零轴半幅」规则,同上。
- **本看板无板块涨跌条**(无单向归一规则应用)。

## 特色纪律与口径

- **跨日尺度声明**:周度中期视角(ma60/120/250、alpha、ADX、板块周度轮动),与日内的日 K 级视角不同。
- **VIX 定性推断**:⚠️ 精确值未取得 · 定性推断。Wind 本次不可调用、联网搜索无返回时,基于本周全球 risk-off 收敛证据做方向推断,已如实标注,非精确读数。绝不填编造数值。
- **未结事项清算纪律**:逐条做出明确决定(已解决 / 转长期跟踪 / 转下周观察 / 放弃),不留"观察中"悬空。
- **下周事件预告口径**:仅标注时间与议题,不预测结果。这是下周每个交易日早间推送的起点——已知的不确定性清单,不是预测报告。
- **板块轮动口径**:板块轮动判断只描述"资金过去几周往哪儿走"的客观事实,不预测下周哪个板块会涨。
- **北向资金口径**:实时净流向自 2024 年起不再高频披露,如实标注,不编造精确值。
- **免责**:所有均线/支撑/压力价位均为参考位,非下单指令。条件式情景为"若…则…"对称可能性,不构成对下周涨跌方向的预测。短期机会与中长期持仓分栏呈现、口径不混用。VIX 精确值未能从可用专业源取得,为基于全球 risk-off 收敛证据的定性推断。
