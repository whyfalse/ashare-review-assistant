# 早间消息推送看板规格

## 面向报告

本规格面向 `ashare-morning-brief` 在 A 股交易日开盘前(典型 8:00–8:20 集合竞价前窗口)产出的早间消息推送报告。报告聚焦"隔夜外盘 + 消息面":**不含 A 股当日行情数据**(涨跌家数/资金面/板块涨跌/亚太收盘),**不含四维深度技术卡片**(盘前不跑引擎),技术参考位仅承接昨晚晚间复盘已算好的结果。VIX 恐慌指数是本看板的核心一级元素——首屏 Hero 专设 VIX KPI,并在隔夜美股详情区设专用卡片。

## 看板整体架构

从上到下分区顺序:

1. **顶部窄标题**:看板名 + 日期 + 数据源说明锚点。
2. **特别说明横幅**(条件渲染):周末版/假期版专用,dashed 边框小横幅;非周末非假期整块隐藏。
3. **HERO 首屏核心结论**:隔夜外盘总览定性(大字) → 美股三指数 KPI(三列网格) → VIX 专用条(阈值色条仪表盘 + 情绪徽章,一级元素) → A50 期货 KPI → 持仓/自选隔夜联动速览彩色芯片。
4. **隔夜美股详情**:四大指数行式列表(收盘 + 涨跌幅 + 简评) + 中概 ADR 行 + 美债/美元/商品四格 + VIX 专用卡片(warn-soft 纯色背景) + 美股事件→国内板块关联映射。
5. **欧洲及全球市场**:四大欧股指数行式列表(弱化 dim 色) + 全球宏观事件 muted-box(不含亚太,亚太在晚间复盘)。
6. **隔夜消息汇总**:四个 details 折叠(国内政策与监管 / 行业与产业动态 / 公司层面 / 国际重大事件),默认国内政策+行业产业两组展开;公司层面带 rel-badge(🔴直接相关 / 🟡间接相关 / 无直接关联)。
7. **今日技术参考位**:隔夜外盘定性收口块 + 持仓参考位 div 卡片(不用 table,两列:支撑/压力/均线/过热超卖) + 参考位说明段落。
8. **短期机会发掘**(独立分栏,蓝色左边框):机会卡片列表(标题 + 分类 + 描述)。
9. **昨晚隔夜观察事项核对**:check-item 卡片逐条跟进(标题 + 来源 tag + 核对结果)。
10. **今日已知日程**:sched-card 列表(日期 + 主题 tag + 事件 + 说明),仅标注不预测。
11. **已完成宏观更新队列**:macro-q-item 条目(分类 + 维度 + 描述 + 影响)。
12. **今日观察清单**:obs-item 卡片列表(标题 + 来源色码 + 描述) + 中长期持仓提示横幅。
13. **页脚**:数据源说明 + 免责声明。

纪律措辞位预留:
- **参考位"非下单指令"**:第 7 区技术参考位卡片标题 + 参考位说明段落尾 + 页脚免责。
- **对称情景双向**:本模板不含 A 股当日行情,对称情景主要承接晚间复盘遗留,在观察清单与参考位中体现。
- **短期机会与中长期持仓分栏**:第 8 区独立蓝色左边框分栏。
- **风险提示与免责**:页脚 disc。

## 模块细节

### 顶部窄标题
- **对应数据**:报告头日期。
- **展示形式**:窄标题行(衬线 17px) + 日期(等宽 12px dim) + src-flag 锚点徽章。
- **数据缺失处理**:无。

### 特别说明横幅(条件渲染)
- **对应数据**:报告"特别说明"(周末版/假期版专用)。
- **展示形式**:dashed 边框小横幅,warn 色小字。
- **数据缺失处理**:**非周末/非假期 → 整块隐藏**(不渲染空横幅)。

### ① HERO 首屏核心结论
- **对应数据**:报告"今日技术参考位 → 隔夜外盘定性"定性收口 + 美股三大指数(道指/纳指/标普) + VIX + A50 期货 + 持仓/自选隔夜联动速览。
- **展示形式**:hero-headline 大字定性结论(22px 衬线黑体) → kpi-row 三列网格(美股三指数 KPI) → VIX 专用条 vix-kpi(阈值色条仪表盘:0–15 绿/15–20 浅黄/20–30 黄/30–40 橙/>40 红,指示点 + 情绪徽章"平静/谨慎/恐慌"等) → A50 KPI → hold-strip 持仓速览彩色芯片。
- **数据缺失处理**:VIX 缺失 → VIX KPI 显示"—"并标"VIX 本次未获取",阈值色条隐藏;A50 缺失 → 隐藏该 KPI;持仓无数据 → 隐藏持仓速览条;美股指数缺失 → 该 KPI"—"灰显。
- **特殊说明**:VIX 仪表盘指示点用 `margin-left` 居中,**不用 transform**(邮件客户端 transform 渲染不可靠)。

### ② 隔夜美股详情
- **对应数据**:报告"隔夜美股"四大指数 + 中概 ADR + 美债/美元/商品 + VIX + 事件映射。
- **展示形式**:idx-row 行式列表(四大指数:收盘 + 涨跌幅 + 简评) + 中概 ADR 行(如金龙中国指数) + macro-grid 四格(2年期/10年期美债收益率、美元指数、原油/黄金) + vix-card VIX 专用卡(warn-soft 纯色背景,**不用 linear-gradient 叠层**) + event-map 事件映射(美股事件 → 国内板块关联)。
- **数据缺失处理**:指数收盘缺失 → faint "—"灰显;中概 ADR 缺失 → 隐藏该行;事件映射缺失 → 隐藏 event-map 块。
- **特殊说明**:VIX 卡片用纯色 `var(--warn-soft)`,不用 `linear-gradient` 叠层(邮件兼容)。

### ③ 欧洲及全球市场
- **对应数据**:报告"欧洲市场"表(英国富时/德国 DAX/法国 CAC/欧洲斯托克) + 全球宏观事件。
- **展示形式**:eu-row 行式列表(弱化 dim 色) + muted-box 全球宏观事件小字块。
- **数据缺失处理**:收盘缺失 → faint "—"。
- **特殊说明**:**不含亚太**——完整亚太数据见前一日晚间复盘报告。看板须在区块底部小字注明"亚太市场见昨日晚间复盘"。

### ④ 隔夜消息汇总
- **对应数据**:报告"隔夜消息汇总"四组(国内政策与监管 / 行业与产业动态 / 公司层面 / 国际重大事件)。
- **展示形式**:四个 details 折叠;默认国内政策 + 行业产业两组展开,公司层面 + 国际事件两组折叠;news-item 带圆点 + 简述;公司层面 comp-row 带 rel-badge(🔴直接相关 / 🟡间接相关 / 无直接关联)。
- **数据缺失处理**:某组无内容 → 该 details 隐藏或摘要标"本组无";单条缺失 → 不编造。
- **特殊说明**:details 折叠在邮件客户端可能默认展开(部分客户端忽略 `open` 属性),须保证默认展开的两组即使被强制折叠也能读到摘要。

### ⑤ 今日技术参考位
- **对应数据**:报告"今日技术参考位"(承接昨晚晚间复盘,盘前不现算)——持仓股/自选股的支撑/压力/均线/过热超卖位。
- **展示形式**:overnight-qual 定性收口块(隔夜外盘对 A 股开盘的影响一句话) → ref-card div 卡片(**不用 table**,用 ref-grid 两列网格:标的 + 支撑位 + 压力位 + 关键均线 + 过热/超卖标注) → ref-notes 参考位说明段落(尾注"均为参考位,非下单指令")。
- **数据缺失处理**:某标的参考位缺失 → 对应格"—"灰显;整节缺失 → 标"本次未提供技术参考位"。
- **特殊说明**:**承接昨晚晚间复盘 · 盘前不现算**;**均为参考位,非下单指令**。用 div 卡片不用 table(邮件兼容,且移动端窄屏 table 易溢出)。

### ⑥ 短期机会发掘(独立分栏)
- **对应数据**:报告"短期机会发掘"——每条机会(标的/催化剂/为何值得注意),由 `ashare-opportunity-discovery` scope=short-term 产出。
- **展示形式**:opp-sec 独立分栏(strength 色左边框) → opp-card 机会卡片列表(标题 + 分类 tag + 描述)。
- **数据缺失处理**:报告未提供本节 → 整块标"本次未提供短期机会发掘";无机会 → empty-card 空态卡 + 原因。
- **特殊说明**:口径与中长期持仓分开,不混用。

### ⑦ 昨晚隔夜观察事项核对
- **对应数据**:报告"隔夜观察核对"——昨晚晚间复盘遗留的观察事项逐条跟进。
- **展示形式**:check-item 卡片(ci-head 带 tag 来源 + ci-body 核对结果)。
- **数据缺失处理**:无核对结果 → 标"待今日盘中验证";无遗留观察 → 空态卡片"昨晚无遗留观察事项"。

### ⑧ 今日已知日程
- **对应数据**:报告"今日日程"——已知事件(时间/议题)。
- **展示形式**:sched-card 卡片列表(日期 + 主题 tag + 事件 + 说明)。
- **数据缺失处理**:无日程 → 隐藏整块。
- **特殊说明**:**仅标注,不预测结果**。

### ⑨ 已完成宏观更新队列
- **对应数据**:报告"宏观更新队列"——本次已完成的宏观记忆更新条目。
- **展示形式**:macro-q-item 条目列表(分类 + 维度 + 描述 + 影响)。
- **数据缺失处理**:队列 0 条 → 渲染空态"本次无宏观更新",不删整块(保留以体现已检查)。

### ⑩ 今日观察清单
- **对应数据**:报告"今日观察清单"——合并技术参考位 / 昨晚遗留 / 隔夜消息 / 今日日程得出的观察项。
- **展示形式**:obs-item 卡片列表(标题 + obs-src 来源色码徽章 + 描述) + lt-hint 中长期持仓提示横幅(弱化)。
- **数据缺失处理**:无观察项 → 空态卡片。
- **特殊说明**:**仅作观察标记,非操作建议**。

### 页脚
- **对应数据**:报告完成时间 + 数据源说明。
- **展示形式**:meta 小字(等宽 11.5px faint) → disc 免责声明。
- **特殊说明**:免责声明须含"所有支撑/压力/均线价位均为参考位,非下单指令""条件式情景描述的是'若…则可能…'的对称可能性,不构成对涨跌方向的预测"。

## 本看板额外样式与比例条规则

本看板无额外配色或字体(复用共享设计系统)。独有组件类名约定:

- `.special-note`:周末/假期特别说明横幅(dashed 边框)。
- `.vix-kpi` / `.vix-gauge`:VIX 专用条与阈值色条仪表盘(指示点用 `margin-left` 居中,**不用 transform**)。
- `.vix-card`:VIX 专用卡片(warn-soft **纯色**背景,不用 linear-gradient)。
- `.macro-grid`:美债/美元/商品四格网格。
- `.eu-row`:欧洲指数行式列表(弱化 dim 色)。
- `.ref-card` / `.ref-grid`:技术参考位 div 卡片(**不用 table**)。
- `.opp-sec` / `.opp-card`:短期机会分栏(strength 色左边框)。
- `.check-item`:隔夜观察核对卡片。
- `.sched-card`:今日日程卡片。
- `.macro-q-item`:宏观更新队列条目。
- `.obs-item` / `.lt-hint`:今日观察清单卡片 + 中长期持仓提示横幅。

**比例条规则应用**:**本看板无比例条**(不含 A 股当日行情,无涨跌家数/板块涨跌/资金分流条)。VIX 仪表盘指示点用 `margin-left` 居中定位,不依赖 script。

## 特色纪律与口径

- **隔夜消息口径**:本看板聚焦"隔夜外盘 + 消息面",不含 A 股当日行情数据(涨跌家数/资金面/板块涨跌/亚太收盘),不含四维深度技术卡片(盘前不跑引擎),技术参考位仅承接昨晚晚间复盘已算好的结果。
- **周末版口径**:周末版须在特别说明横幅注明"今日为周日,A股休市。本推送覆盖周五收盘后至周日的完整周末消息窗口,为下周一开盘做准备。取数工具以联网搜索为主,所有精确数字均来源于公开搜索、未经专业金融源核对"。
- **VIX 核心地位**:VIX 恐慌指数是本看板的核心一级元素——首屏 Hero 专设 VIX KPI,并在隔夜美股详情区设专用卡片。
- **邮件兼容本看板特有细节**:① 技术参考位与隔夜核对均用 div 卡片,不用 table,不用 @media 切换视图;② VIX 仪表盘指示点用 `margin-left` 居中,不用 transform;③ VIX 卡片用纯色,不用 linear-gradient 叠层。(通则"无 `<script>`、条宽生成时内联"见 SKILL.md「共享设计系统」)
- **免责**:所有支撑/压力/均线价位均为参考位,非下单指令;条件式情景描述的是"若…则可能…"的对称可能性,不构成对涨跌方向的预测。
