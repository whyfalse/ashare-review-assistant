# 盘中复盘看板规格

## 面向报告

本规格面向 `ashare-intraday-review` 在 A 股交易日盘中(典型 14:30–14:45 收盘前窗口)产出的快速复盘报告。报告内容只含两块:① 大盘/资金流向/板块温度计(盘中快照,非收盘数据);② 短期机会发掘(由 `ashare-opportunity-discovery` scope=intraday 产出)。该技能为独立技能,**不读取持仓/自选股/宏观记忆,不承接昨晚晚间复盘参考位,也不向其他复盘技能回写**,看板同样遵守这一边界。

## 看板整体架构

从上到下分区顺序:

1. **顶部窄标题**:看板名 + 日期 + 时间窗口 + "⚠️ 盘中快照"锚点徽章(warn 色)。
2. **盘中快照警示条**:贯穿全篇的基调提醒——"本看板数据为 14:30 前后盘中实时快照,非收盘数据;仅描述当日盘面现象,不预测方向、不构成操作建议"。warn-soft 背景 + warn-border 边框,挂在顶部之下、所有内容之上。
3. **HERO 首屏核心结论**:大字风格判断(如"医药防御反弹 · 科技内部极致分化")→ 上证现价三件套(现价 + 涨跌幅 + 盘中最低刺破/收复备注)→ KPI 两格(主要指数分化 / 上证涨跌家数)。
4. **大盘 / 资金流向 / 板块温度**:指数小格 2 列(科创/上证/深证/创业,唯一显著红盘的标 warn tag)→ 实时资金流向(中心零轴横向条形,流入红/流出绿,带"上午 ~10:26 快照"warn tag)→ 板块涨跌横向条形(领涨 Top N + 领跌 Top N,半导体内部分化等结构性提示)→ 资金流向与板块涨跌为盘中快照 info banner。
5. **短期机会发掘**(独立分栏,蓝色左边框):分栏口径声明(短期催化剂驱动型,与中长期持仓口径不同,不构成操作建议)→ 机会卡片列表(标题 + 描述,描述里加粗关键数字与逻辑)。
6. **页脚**:报告完成时间 + 数据截止(盘中快照非收盘)+ 数据源说明 → 免责声明(独立技能产出边界 + 分栏口径 + 不构成操作建议)。

纪律措辞位预留:
- **盘中快照非收盘数据**:顶部警示条 + 资金流向/板块涨跌 banner + 页脚 meta,三处贯穿。
- **短期机会与中长期持仓分栏**:第 5 区独立蓝色左边框分栏 + 口径声明卡片。
- **不预测方向、不构成操作建议**:顶部警示条 + 页脚免责。

## 模块细节

### ① 顶部窄标题
- **对应数据**:报告头日期 + 时间窗口(14:30–14:45)。
- **展示形式**:窄标题行(衬线大字 17px) + 日期(等宽小字) + "⚠️ 盘中快照"warn 色圆角徽章(右锚)。
- **数据缺失处理**:无。

### ② 盘中快照警示条
- **对应数据**:固定文案,基调提醒。
- **展示形式**:warn-soft 背景 + warn-border 边框圆角条,11.5px 小字,加粗"⚠ 盘中快照"。
- **数据缺失处理**:无(固定渲染)。

### ③ HERO 首屏核心结论
- **对应数据**:报告"大盘/资金流向/板块温度计"开篇风格判断一句话 + 上证现价/涨跌 + 盘中最低刺破/收复备注 + 主要指数分化 + 上证涨跌家数。
- **展示形式**:sec-eye 小标签(intraday · 核心结论) → hero-headline 大字风格判断(21px 衬线黑体,关键短语用 .up/.down 染色) → hero-desc 一句话描述(12.5px dim) → hero-idx 上证现价三件套盒(现价 24px 等宽 + 涨跌幅 + 盘中最低备注副行) → kpi-row 两格(主要指数分化 / 上证涨跌家数,数字 19px 等宽)。
- **数据缺失处理**:上证现价缺失 → KPI 显示"—"灰显;涨跌家数缺失 → 隐藏该 KPI 并在该格标"涨跌家数缺失";风格判断缺失 → hero-headline 改显"盘中风格判断缺失"灰字,不编造结论。
- **特殊说明**:hero-headline 关键短语(如"科技内部极致分化")用 .up/.down 染色,与正文颜色双编码方向。

### ④ 大盘 / 资金流向 / 板块温度
- **对应数据**:报告"大盘/资金流向/板块温度计"节——主要指数盘中涨跌(科创/上证/深证/创业) + 实时资金流向(主力净流入/流出 Top N 行业) + 板块涨跌(领涨/领跌 Top N + 结构性分化提示)。
- **展示形式**:
  - 指数小格:idx-grid 2 列,每格 idx-cell(指数名 + 涨跌幅大字 + 现价/盘中备注小字);唯一显著红盘的指数加 hi 高亮边框 + warn tag"唯一显著红盘"。
  - 资金流向:flow-row 网格(96px 名称 / 1fr 零轴条 / 64px 数值),零轴居中(50% 处 1px border 竖线),流入红色条向右、流出绿色条向左;顶部 warn tag 标"上午 ~10:26 快照"。下方 takeaway 一句话结论(加粗"高低切换"等关键判断)。
  - 板块涨跌:两组 sec-row(领涨 Top N + 领跌 Top N),每组名称 + 横向条形 + 涨跌幅;下方 takeaway 点出结构性分化(如"半导体材料设备 +1.68% vs 产品 −0.24%")。
  - 底部 info banner:"资金流向与板块涨跌为上午盘中快照,非收盘数据,仅供方向性参考"。
- **数据缺失处理**:指数缺失 → 该格"—"灰显;资金流向缺失 → 整块标"本次未提供资金流向";板块缺失 → 标"本次未提供板块数据";资金流向与板块涨跌时间戳缺失 → 隐藏 warn tag,不补造时间。
- **特殊说明**:资金流向条用「中心零轴半幅」规则;板块涨跌条用「单向归一」规则(见下文"比例条规则应用")。

### ⑤ 短期机会发掘(独立分栏)
- **对应数据**:报告"短期机会发掘"节——每条机会(标题 + 催化剂描述 + 关键数字),由 `ashare-opportunity-discovery` scope=intraday 产出。
- **展示形式**:opp-split-note 分栏口径声明卡片(strength 色边框 + 虚线,加粗"⚠ 分栏口径") → opp-card 机会卡片列表(strength 色左边框,标题 14px 衬线 + 描述 12.5px,关键数字与逻辑短语加粗)。
- **数据缺失处理**:整节缺失 → 标"本次未提供短期机会发掘";无机会(报告明示"今日未发掘") → 渲染 empty-card 空态卡 + 原因;单条机会缺失 → 不渲染该卡,不编造。
- **特殊说明**:本看板不含中长期持仓栏(独立技能不读持仓),故短期机会分栏单独成块,不存在"分栏对比"的视觉冲突,但口径声明仍保留以纪律一致。

### 页脚
- **对应数据**:报告完成时间 + 数据截止(盘中快照非收盘) + 数据源说明(实时快照;资金流向/板块涨跌为上午 ~10:26 盘中快照)。
- **展示形式**:meta 小字(等宽 11.5px faint) → disc 免责声明(11.5px faint,加粗关键短语)。
- **数据缺失处理**:无。
- **特殊说明**:免责声明须含"本看板为独立技能产出,不读取持仓/自选股/宏观记忆,不承接昨晚技术参考位,也不向其他复盘技能回写"。

## 本看板额外样式与比例条规则

本看板无额外配色或字体(复用共享设计系统)。独有组件类名约定(生成时按描述构建):

- `.snap-warn`:盘中快照警示条(warn-soft 背景 + warn-border 边框,8px 圆角)。
- `.hero-headline`:21px 衬线黑体,关键短语内联 .up/.down 染色。
- `.flow-row` / `.flow-track` / `.flow-track .zero` / `.flow-track .fill`:资金流向零轴横向条形(96px 名称 / 1fr 条轨 / 64px 数值,条轨高 14px,零轴 1px 竖线居中)。
- `.sec-row` / `.sec-name` / `.sec-track` / `.sec-fill`:板块涨跌横向条形(104px 名称 / 1fr 条轨 / 56px 数值,条轨高 12px)。
- `.idx-cell` / `.idx-cell.hi`:指数小格(hi 为唯一显著红盘高亮,加 warn-border + 渐变背景)。
- `.opp-card` / `.opp-split-note`:短期机会卡片(strength 色左边框) + 分栏口径声明卡片(虚线边框)。

**比例条规则应用**(规则定义见 SKILL.md「共享设计系统」,此处只标注本看板哪些组件用哪条):

- **资金流向条**(`.flow-track .fill`):用「中心零轴半幅」规则。流入红色(`var(--up)`)向右,流出绿色(`var(--down)`)向左。
- **板块涨跌条**(`.sec-fill`):用「单向归一」规则。领涨组与领跌组分别取组内 M,领涨红色、领跌绿色。

## 特色纪律与口径

- **盘中快照非收盘数据**:看板数据为 14:30 前后盘中实时快照,非收盘数据;仅描述当日盘面现象(指数、资金流向、板块冷热、涨跌停结构),不预测方向、不构成操作建议。这一警示在顶部警示条、资金流向/板块涨跌 banner、页脚 meta 三处贯穿。
- **独立技能边界**:本看板为独立技能产出,不读取持仓/自选股/宏观记忆,不承接昨晚晚间复盘参考位,也不向其他复盘技能回写。短期机会与中长期持仓分栏呈现、口径不混用。
- **结构性分化提示**:盘中看板重视"结构性分化"(如半导体材料设备 vs 产品、科技内部高低切换),takeaway 一句话结论须点出分化方向与幅度,但不预测次日。
