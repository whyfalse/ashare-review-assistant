# 晚间复盘看板规格

## 面向报告

本规格面向 `ashare-evening-review` 在 A 股收盘后当晚产出的晚间复盘报告。报告以 A 股当日全天表现为主,涵盖指数表现/资金面/板块/大盘技术面/持仓自选四维深度卡片/对称情景/短期机会/板块轮动/消息面/亚太市场/隔夜观察与技术参考位移交。看板是当日复盘的"主报告",也是次日早间推送的数据上游(技术参考位移交)。

## 看板整体架构

从上到下分区顺序:

1. **顶部窄标题**:看板名 + 日期 + 数据源说明锚点。
2. **HERO 首屏核心结论**:大字定性(如"高低切换 · 科技内部极致分化") → 上证收盘大字三件套(现价 + 涨跌幅 + 成交额) → KPI 三件套(成交额/上涨占比/主力资金) → 涨跌家数占比条(三段 span) → 持仓速览彩色芯片。
3. **指数表现**:五大指数(上证/深证/创业/科创/北证)行式列表(名称 + 收盘 + 涨跌幅 + 成交额副行)。
4. **主力资金面**:净流出大字 → 中心零轴分流条(超大单/大单/中单/小单,流出左绿/流入右红) → 北向/南向小字。
5. **领涨/领跌板块**:两栏卡片(移动端上下堆叠),横向条形 + 涨跌幅 + 领涨股/特征小字。
6. **大盘技术面**:四大指数逐张卡片(状态横幅 + 指标小格 + 支撑压力 + 对称情景折叠 details)。
7. **持仓/自选四维深度卡片**(中长期持仓栏):每只一个 details,展开体六维明细(技术面/资金面/消息面/相对强弱 alpha vs beta/对称情景/技术位参考)。
8. **短期机会发掘**(独立分栏,蓝色左边框):机会卡片或空态卡。
9. **板块轮动持续性**:轮动方向文字块 + 持续性定性卡片 + 持仓板块定位卡片。
10. **白天消息面**:四组 details 折叠(国内政策与监管 / 行业与产业动态 / 公司层面 / 国际重大事件),公司层面带 rel-badge(🔴持仓)。
11. **亚太市场**(辅助弱化):asia-card 弱化卡片 + 联动 muted-box。
12. **隔夜需观察事项 + 技术参考位移交**:watch-item 观察清单卡片 + ref-card 技术参考位卡片(表格转卡片)。
13. **收尾小项**:已完成宏观更新队列(弱化小卡片)。
14. **页脚**:数据源说明 + 免责声明。

纪律措辞位预留:
- **对称情景双向 + 参考位"非下单指令"**:第 6 区大盘技术面每张卡片 scenario 块、第 7 区持仓四维卡片 05 块、第 12 区技术参考位移交 nd-tag。
- **短期机会与中长期持仓分栏**:第 7 区为中长期持仓栏,第 8 区为短期机会独立蓝色左边框分栏。
- **风险提示与免责**:页脚 disc。

## 模块细节

### ① HERO 首屏核心结论
- **对应数据**:报告"今日A股全天回顾"开篇定性 + 上证收盘 + 涨跌家数/成交额/主力净流出 + 持仓自选股今日涨跌。
- **展示形式**:hero-headline 大字定性结论(22px 衬线黑体,关键短语 .up/.down 染色) → hero-idx 上证收盘三件套(现价 30px 等宽 + 涨跌幅 + 成交额副行) → kpi-row 三列网格(成交额 / 上涨占比 / 主力资金,数字 19px 等宽) → breadth-bar 涨跌家数占比条(三段 span:涨红/平灰/跌绿,下方小字"涨 789 / 平 62 / 跌 4674") → hold-strip 持仓速览彩色芯片(持仓股代码 + 涨跌幅染色)。
- **数据缺失处理**:上证收盘缺失 → KPI 显示"—"灰显;涨跌家数缺失 → 隐藏 breadth 条并小字"涨跌家数缺失";持仓缺失 → 隐藏持仓速览条;定性结论缺失 → hero-headline 改显"今日全天定性缺失"灰字。
- **特殊说明**:涨跌家数条用「分段比例」规则。

### ② 指数表现
- **对应数据**:报告"指数表现"表(指数/收盘/涨跌幅/成交额)。
- **展示形式**:单栏行式列表 idx-row(三列网格:名称 / 收盘价 / 涨跌幅,下方成交额副行),涨跌幅大字 + ▲/▼ 双编码。
- **数据缺失处理**:收盘或成交额缺失 → 该格"—"灰显;整只指数缺失 → 该行灰显并末尾标"(本次未提供)"。

### ③ 主力资金面
- **对应数据**:报告"资金面"(主力净流出/超大单/大单/中单/小单/北向/南向)。
- **展示形式**:净流出大字(28px 等宽,跌色) → flow-rows 中心零轴分流条(流出左绿/流入右红,超大单/大单/中单/小单四行) → flow-note 北向/南向小字。
- **数据缺失处理**:分项缺失 → 该行灰显并标"—";北向异常 → 保留原值并加"数据异常待核实"标注,不删除。
- **特殊说明**:资金分流条用「中心零轴半幅」规则。

### ④ 领涨/领跌板块
- **对应数据**:报告"领涨板块""领跌板块"表。
- **展示形式**:两栏卡片(移动端上下堆叠),sec-row 横向条形 + 涨跌幅 + 领涨股/特征小字。
- **数据缺失处理**:板块涨幅缺失 → 该行条形隐藏、数值"—"灰显;整组缺失 → 该卡片标"本次未提供板块数据"。
- **特殊说明**:条宽按组内 1.1 倍最大值归一(单向归一规则)。

### ⑤ 大盘技术面
- **对应数据**:报告"大盘技术面"各指数段(均线排列/ADX/量价/MACD-KDJ/乖离/关键位/状态/对称情景)。
- **展示形式**:每指数一张 tech-card:tech-head(名称 + 涨跌) → banner 状态横幅(takeaway 一句话,warn/info/strength/down 四色) → metric-grid 四格指标(均线排列 / ADX / 量价 / MACD-KDJ) → level-row 支撑压力 tag → scenario 对称情景折叠 details(双向:乐观情景 + 谨慎情景,末尾 nd-tag"参考位,非下单指令")。
- **数据缺失处理**:某指标缺失 → 该小格"—"灰显;整只指数技术面缺失 → 卡片降级为"本次未提供技术面";对称情景缺失 → 隐藏该块。
- **特殊说明**:banner 色调与涨跌色区分,靠文字双编码(warn 警示/info 中性/strength 强化/down 偏弱)。

### ⑥ 持仓/自选四维深度卡片(中长期持仓栏)
- **对应数据**:报告"持仓/自选股四维深度卡片"逐只(技术面/资金面/消息面/相对强弱/对称情景/技术位参考)。
- **展示形式**:每只一个 details:summary = 代码名称 + 涨跌 + 状态扫描层(技术面状态徽章) → 展开体 hold-body 六个 dim-block(01技术面 / 02资金面 / 03消息面 / 04相对强弱 alpha vs beta / 05对称情景 / 06技术位参考)。04 块 alpha-chips 展示 alpha 20日/60日;05 块含 nd-tag"参考位,非下单指令";消息面/警示用 disc-box(warn-soft / calm-muted 三色)。
- **分栏**:本块为【中长期持仓/自选】栏,与下方"短期机会"分栏呈现、口径不混用。
- **数据缺失处理**:某维度缺失 → 该块灰显并标"本次未提供";alpha 缺失(如 ETF) → 显示"ETF不算 alpha"说明;自选无持仓 → 技术位参考块标"无持仓"。
- **特殊说明**:alpha-chips 展示 alpha 20日/60日;disc-box(warn-soft/calm-muted 三色)承载警示/冷静/中性提示。

### ⑦ 短期机会发掘(独立分栏)
- **对应数据**:报告"短期机会发掘"(标的/催化剂/为何值得注意,或"今日未发掘"+原因)。
- **展示形式**:opp-sec 独立分栏(strength 色左边框);有机会 → opp-card(标题 + 分类 tag + 描述);无 → empty-card 空态卡 + 原因。
- **数据缺失处理**:报告未提供本节 → 整块标"本次未提供短期机会发掘"。
- **特殊说明**:口径与中长期持仓分开,不混用。

### ⑧ 板块轮动持续性
- **对应数据**:报告"板块轮动持续性"(轮动方向/领涨持续性定性/持仓板块定位)。
- **展示形式**:muted-box 延续性 + 切换文字块 → rot-card 持续性定性卡片列表 → rot-card 持仓板块定位卡片列表。
- **数据缺失处理**:某板块定性缺失 → 该卡片对应字段"—";整节缺失 → 标"本次未提供"。

### ⑨ 白天消息面
- **对应数据**:报告"白天消息面"四组(国内政策与监管 / 行业与产业动态 / 公司层面 / 国际重大事件)。
- **展示形式**:每组一个 details(密度控制·折叠),公司层面带 rel-badge(🔴持仓)。
- **数据缺失处理**:某组无内容 → 该 details 隐藏或摘要标"本组无";单条缺失 → 不编造。

### ⑩ 亚太市场(辅助弱化)
- **对应数据**:报告"亚太市场"表(日经/韩国综合/恒生/澳洲等) + 与 A 股联动/背离客观陈述。
- **展示形式**:asia-card 弱化卡片(panel-2 色,非主色) + 熔断 badge(若有) + muted-box 联动陈述。
- **数据缺失处理**:某市场缺失 → 该卡"—"灰显;联动陈述缺失 → 隐藏 muted-box。
- **特殊说明**:**仅客观陈述不预测次日**;海外隔夜行情由次日 `ashare-morning-brief` 跟踪。

### ⑪ 隔夜需观察事项 + 技术参考位移交
- **对应数据**:报告"隔夜需观察事项"表 + "技术参考位移交"表(供次日早间推送承接)。
- **展示形式**:watch-item 观察清单卡片(标的 / 关注原因 / 观察类型 badge) → ref-card 技术参考位卡片(昨收 / 支撑 / 压力 / 均线 / 警示,**表格转卡片**,nd-tag"参考位,非下单指令")。
- **数据缺失处理**:某标的参考位缺失 → 对应格"—"灰显;无警示 → 显示"—"。
- **特殊说明**:**观察标记非操作建议**;**参考位非下单指令**。

### ⑫ 收尾小项
- **对应数据**:报告"已完成宏观更新队列"。
- **展示形式**:mini 弱化小卡片;宏观队列 0 条时用 b0 徽章 + 依据列表(保留判断依据,不删)。
- **数据缺失处理**:队列 0 条 → 保留判断依据,不删整块。

### 页脚
- **对应数据**:报告完成时间 + 数据源说明。
- **展示形式**:meta 小字(等宽 11.5px faint) → disc 免责声明。
- **特殊说明**:免责含"亚太市场数据来自联网搜索(定性信息,精确数字未经专业源核对)"。

## 本看板额外样式与比例条规则

本看板无额外配色或字体(复用共享设计系统)。独有组件类名约定:

- `.hero-idx` / `.kpi-row` / `.breadth-bar`:首屏三件套 + KPI 网格 + 涨跌家数占比条。
- `.idx-row`:指数表现行式列表。
- `.flow-rows` / `.flow-note`:资金分流条 + 北向南向小字。
- `.sec-row`:板块涨跌横向条形。
- `.tech-card` / `.metric-grid` / `.level-row` / `.scenario`:大盘技术面卡片 + 指标小格 + 支撑压力 tag + 对称情景折叠。
- `.hold-body` / `.dim-block` / `.alpha-chips` / `.disc-box`:持仓四维展开体 + 六维明细 + alpha 芯片 + 警示盒。
- `.opp-sec` / `.opp-card` / `.empty-card`:短期机会分栏 + 机会卡 + 空态卡。
- `.rot-card` / `.muted-box`:板块轮动持续性卡片 + 弱化文字块。
- `.asia-card`:亚太市场弱化卡片。
- `.watch-item` / `.ref-card` / `.nd-tag`:观察清单 + 技术参考位卡片 + "非下单指令"徽章。

**比例条规则应用**(规则定义见 SKILL.md「共享设计系统」,此处只标注本看板哪些组件用哪条):

- **涨跌家数占比条**(`.breadth-bar` 三段 span):用「分段比例」规则。涨红/平灰/跌绿三段,下方小字标绝对数。
- **资金分流条**(`.flow-rows .fill`):用「中心零轴半幅」规则。流入红色向右,流出绿色向左。
- **板块涨跌条**(`.sec-row .sec-fill`):用「单向归一」规则。领涨组与领跌组分别取组内 M,领涨红色、领跌绿色。

## 特色纪律与口径

- **晚间复盘口径**:所有数字/文字均为【示意占位】,生成时用真实数据源内容逐处替换;架构、分区顺序、样式、纪律措辞位保留不动。缺失字段按各模块"缺失时"规则渲染("—"灰显 / "数据缺失"标注 / 整块降级),绝不编造或外推。
- **亚太市场弱化**:亚太市场数据来自联网搜索(定性信息,精确数字未经专业源核对),仅客观陈述不预测次日;海外隔夜行情由次日早间推送跟踪。
- **技术参考位移交**:技术参考位卡片是次日早间推送的数据上游,须完整移交(昨收/支撑/压力/均线/警示),nd-tag"参考位,非下单指令"必显。
- **免责**:本报告中的技术分析指标由 compute_indicators.py 计算(无 Wind MCP 核对)。亚太市场数据来自联网搜索(定性信息,精确数字未经专业源核对)。所有支撑/压力/均线价位均为参考位,非下单指令。条件式情景描述的是"若…则可能…"的对称可能性,不构成对明日涨跌方向的预测。短期机会与中长期持仓分栏呈现、口径不混用。
