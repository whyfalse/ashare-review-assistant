# 风险体检看板规格

## 面向报告

本规格面向 `ashare-risk-assessment` 产出的 A 股投资风险评估报告。报告对 A 股大盘/行业板块/具体个股/持仓组合进行全维度投资风险排查,采用分层风险等级(L1-L6)+ 红旗信号清单 + 系统性/非系统性分类 + 组合集中度结构。红旗信号优先于加权平均(命中即总体标高、置顶红底),风险等级为定性判断非精确预测。

## 看板整体架构

从上到下分区顺序:

1. **顶部窄标题**:看板名 + 日期 + 数据源说明锚点。
2. **红旗命中顶部警示横幅**(条件渲染):命中时强制显示,未命中不渲染。置顶红底警示,首屏即见"命中红旗→总体标高的原因"。
3. **HERO 总体风险等级**:分析对象 + 大徽章(四档配色:低绿/中黄/中高橙/高红) + 一句话总体结论 + 四宫格元信息(分析对象/分析范围/数据截止/触发背景)。
4. **红旗信号清单**(置顶·一票否决级):命中 → 红底卡,每条红旗一个 flag-item(名称 + 状态 badge:持续/新增/已解除 + 依据);未命中 → 绿底卡。
5. **六层风险速览热力条**:L1-L6 每层一行(层名 + 对象小字 → 四段热力条 + 等级文字 → 核心结论)。
6. **系统性 vs 非系统性风险**:两栏卡片(系统性红左边框 / 非系统性黄左边框),窄屏堆叠。
7. **组合集中度(L6)**:行业占比横向条 + 产业链环节文字 + 集中度结论 badge。
8. **分层详细分析**(details 折叠):L1-L6 每层一个 details,L5 含个股子块(L5.5事件性 / L5.4估值 / L5.6技术面)。
9. **数据来源与缺口**:来源逐行 + 缺口列表。
10. **页脚**:数据源说明 + 免责声明。

纪律措辞位预留:
- **红旗优先于加权平均**:第 2 区顶部警示横幅 + 第 3 区总体等级强制高 + 第 4 区红旗清单置顶。
- **风险等级为定性判断非精确预测**:第 3 区大徽章下方 + 页脚免责。
- **分层矛盾明说**:第 8 区分层详细分析 det-sub 块。
- **"不构成投资建议"免责**:页脚 disc。

## 模块细节

### 顶部窄标题
- **对应数据**:报告头日期。
- **展示形式**:窄标题行(衬线 17px) + 日期(等宽 12px dim) + src-flag 锚点徽章。
- **数据缺失处理**:无。

### 红旗命中顶部警示横幅(条件渲染)
- **对应数据**:报告红旗命中状态。
- **展示形式**:flag-banner 红底横幅(rk-high-soft 背景 + rk-high 边框 + ⚠️ 图标 + 文案"命中 N 项红旗 → 总体风险强制标高")。
- **数据缺失处理**:**未命中时不渲染本横幅**(不留空位)。
- **特殊说明**:命中时强制显示在 top 之后、hero 之前,首屏即见"命中红旗→总体标高的原因"。

### ① HERO 总体风险等级
- **对应数据**:报告"风险速览"表的"总体风险等级"行 + 报告头(分析对象/分析范围/数据截止/触发背景)。
- **展示形式**:hero-obj 分析对象小字 → risk-badge 大徽章(四档配色:`.low` 绿 / `.mid` 黄 / `.midhigh` 橙 / `.high` 红,徽章大字 + 等级文字) → hero-desc 一句话总体结论 → hero-meta 四宫格元信息(分析对象 / 分析范围 / 数据截止 / 触发背景)。
- **纪律**:**红旗命中时总体强制为"高"且下方 flag-banner 必显,不被六层平均稀释**。
- **数据缺失处理**:总体等级缺失 → 徽章灰显并标"本次未给出总体等级";触发背景缺失 → 该格隐藏。
- **特殊说明**:对应 `ashare-risk-assessment` SKILL.md 的"L6 红旗优先规则"。

### ② 红旗信号清单
- **对应数据**:报告"红旗信号清单"——命中条目(名称/状态/依据)或"未发现"说明 + 与 `risk_flags.json` 历史 open 红旗的核实结果。
- **展示形式**:命中 → flag-card.hit 红底卡,每条红旗一个 flag-item(名称 + 状态 badge:持续/新增/已解除 + 依据小字);未命中 → flag-card.ok 绿底卡"本次未发现红旗信号"。
- **纪律**:**命中任一红旗,总体等级强制为"高",此卡置于最前,不被其他层面正面信息稀释**。
- **数据缺失处理**:报告未提及红旗 → 整块标"本次未做红旗排查";历史 open 红旗本次未核实 → 单独标注"待核实"。
- **特殊说明**:L5.5 红旗状态(持续/新增/已解除)须与 `risk_flags.json` 核实结果一致。

### ③ 六层风险速览热力条
- **对应数据**:报告"风险速览"表各层等级 + 核心结论一句话。
- **展示形式**:每层一行 lvl-row:层名 + 对象小字 → lvl-segs 四段热力条(低|中|中高|高,当前等级段填色发光,其余灰) → 等级文字;下方 lvl-note 核心结论。
- **纪律**:等级颜色 + 文字双编码;红旗命中层(L5.5)等级强制高;全球系统性叠加触发时在 L1/L2/L4 注明。
- **数据缺失处理**:某层"不适用"(如个股场景无 L6) → 四段全灰、等级文字"不适用"、结论行隐藏;某层等级缺失 → 四段全灰并标"—"。
- **特殊说明**:六层热力条的填色与发光段**在生成时按报告各层等级内联到 class/style**,不依赖 script。

### ④ 系统性 vs 非系统性风险
- **对应数据**:报告"系统性风险 vs 非系统性风险"两栏(风险来源/内容/当前状态)。
- **展示形式**:duo-grid 两栏卡片(移动端并排窄栏,窄屏堆叠):系统性(duo-card.sys 红左边框)= 需仓位管理/对冲应对;非系统性(duo-card.non 黄左边框)= 可分散持仓降低。
- **数据缺失处理**:某栏无内容 → 该卡标"本次未识别此类风险";整节缺失 → 标"本次未做分类"。
- **特殊说明**:窄屏堆叠为单栏,避免文字挤压(断点见 SKILL.md「共享设计系统」移动端规格)。

### ⑤ 组合集中度(L6)
- **对应数据**:报告"持仓组合集中度分析"表(维度/现状/风险判断)——行业占比/产业链环节/核心驱动因子。
- **展示形式**:conc-row 行业占比横向条(单向归一,各行业一条) → muted-box 产业链环节文字 → conc-verdict 集中度结论 badge(分散/适度/集中/高度集中)。
- **数据缺失处理**:单一个股/大盘对象无 L6 → 整块标"L6 不适用本对象"并隐藏;占比数据缺失 → 条形隐藏、数值"—"。
- **特殊说明**:占比条用「单向归一」规则。

### ⑥ 分层详细分析(details 折叠)
- **对应数据**:报告"分层详细分析"各层文字论述 + L5 个股逐只子块表(L5.1-L5.6 等级/异常项)。
- **展示形式**:每层一个 details:summary = 层名 + 等级 tag;展开体 det-body = 该层判断性文字 + (L5) 个股子块卡(sub-grid:L5.5 事件性 / L5.4 估值 / L5.6 技术面)。L5.5 红旗引用红旗清单不重复展开。
- **纪律**:**各层结论互相矛盾时明说矛盾,不和稀泥**;L5.5 红旗引用红旗清单不重复展开。
- **数据缺失处理**:某层不适用本对象 → 该 details 隐藏;某子块缺失 → 标"本次未做"。
- **特殊说明**:det-sub"分层矛盾明说"块承载各层矛盾判断。

### ⑦ 数据来源与缺口
- **对应数据**:报告"数据来源"表(数据大类/来源工具/层级/备注) + "数据缺口"列表。
- **展示形式**:src-row 来源逐行(大类 + 备注 / 工具 + 层级) → gap-item 缺口列表(黄点 + 说明)。
- **数据缺失处理**:来源表缺失 → 标"本次未记录数据来源";无缺口 → 显示"本次无明显数据缺口"。
- **特殊说明**:**如实标注,不掩盖**。

### 页脚
- **对应数据**:报告生成时间 + 数据截止 + 触发方式 + 配套风险体检文件路径。
- **展示形式**:meta 小字(等宽 11.5px faint) → disc 免责声明。
- **特殊说明**:免责含"所有风险等级均为定性判断,不是精确预测""红旗信号优先于加权平均""不构成买入、卖出或持有的投资建议"。

## 本看板额外样式与比例条规则

本看板**额外使用四档风险专用色** `--rk-low/mid/midhigh/high`(低绿/中黄/中高橙/高红,色值见 SKILL.md「共享设计系统」),其他看板不用。等级颜色 + 文字双编码,色弱也能读。独有组件类名约定:

- `.flag-banner` / `.fb-ico` / `.fb-tx`:红旗命中顶部警示横幅(rk-high-soft 背景)。
- `.risk-badge.low` / `.mid` / `.midhigh` / `.high`:四档风险大徽章。
- `.hero-obj` / `.hero-desc` / `.hero-meta`:总体等级区分析对象 + 结论 + 四宫格元信息。
- `.flag-card.hit` / `.flag-card.ok` / `.flag-item`:红旗清单红底卡 / 绿底卡 / 单条红旗。
- `.lvl-row` / `.lvl-segs` / `.lvl-note`:六层热力条行 + 四段热力条 + 核心结论。
- `.duo-grid` / `.duo-card.sys` / `.duo-card.non`:系统性 vs 非系统性两栏卡片。
- `.conc-row` / `.conc-verdict`:组合集中度占比条 + 集中度结论 badge。
- `.det-body` / `.det-sub` / `.sub-grid`:分层详细分析展开体 + 矛盾块 + 个股子块网格。
- `.src-row` / `.gap-item`:数据来源行 + 缺口列表项。

**比例条规则应用**(规则定义见 SKILL.md「共享设计系统」,此处只标注本看板哪些组件用哪条):

- **组合集中度占比条**(`.conc-row .conc-fill`):用「单向归一」规则。各行业占比按组内最大值归一。
- **六层热力条**(`.lvl-segs` 四段):**不是比例条**,是四段离散填色。按当前等级在生成时内联 class(当前段 on + 配色 class,其余灰)。

**额外断点**:窄屏两栏分类(duo-grid / hero-meta)堆叠为单栏,避免文字挤压(断点与规则见 SKILL.md「共享设计系统」移动端规格)。

## 特色纪律与口径

- **风险等级四档配色**:低=绿 / 中=黄 / 中高=橙 / 高=红 / 不适用=灰。等级文字与颜色双编码,色弱也能读。
- **红旗优先规则**:红旗信号优先于加权平均(命中即总体标高、置顶红底)。命中任一红旗,总体等级即强制标"高",不被其他层面正面信息稀释。L5.5 红旗状态(持续/新增/已解除)须与 `risk_flags.json` 核实结果一致。
- **定性非精确预测**:风险等级为定性判断,不是精确预测。
- **分析对象适配**:风险报告支持 大盘/板块/个股/持仓组合 四种对象,覆盖层级不同。六层热力条对"本对象不适用"的层按"缺失时"规则灰显并标"不适用",不得编造等级填满。
- **分层矛盾明说**:各层结论互相矛盾时明说矛盾,不和稀泥(det-sub 块承载)。
- **数据缺口如实标注**:如实标注,不掩盖。
- **免责**:本看板不构成买入、卖出或持有的投资建议,最终投资决策及其风险由投资者结合自身风险承受能力自行判断和承担。所有风险等级均为定性判断,不是精确预测。红旗信号优先于加权平均。
