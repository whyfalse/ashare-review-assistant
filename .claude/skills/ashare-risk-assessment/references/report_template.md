# 风险评估报告模板

撰写最终报告时,以此结构为骨架,用L1-L6的判断结果填充,**不要把检索
字段原样罗列成流水账**——每层都要落到"这意味着什么风险"的判断性文字,
而不是停在"某指标是多少"的事实陈述。

```markdown
# [分析对象]投资风险评估报告

**分析对象**:[大盘 / XX行业板块 / XX股票代码及名称 / 持仓组合]
**分析范围**:[覆盖的层级,如"L1宏观+L2政策+L4市场层面" 或 "L1-L6全部"]
**数据截止日期**:[明确标注,风险信息有时效性]

## 一、风险速览

| 层面 | 风险等级 | 核心结论(一句话) |
|---|---|---|
| L1 宏观环境 | 低/中/高 | ... |
| L2 政策与制度 | 低/中/高 | ... |
| L3 中观行业(如适用) | 低/中/高 | ... |
| L4 市场交易结构与情绪 | 低/中/高 | ... |
| L5 微观个股(如适用) | 低/中/高 | ... |
| **总体风险等级** | **低/中/高** | [是否命中一票否决红旗需在此注明] |

## 二、红旗信号清单(如有,置顶单独展示)

> 如果L5.5命中任何一票否决级别的红旗(ST/立案调查/审计非标/股权
> 冻结等),必须在这里单独列出,并说明这是总体结论定为"高风险"的
> 直接原因,不能被其他层面的正面信息稀释。没有命中时这一节可省略
> 或注明"未发现一票否决级别的红旗信号"。

- [红旗1]:[具体内容 + 发现日期/来源]
- [红旗2]:...

## 三、分层详细分析

### L1 宏观环境
[经济周期阶段判断的文字论述,不是罗列数字;引用支撑判断的关键数据点;
需跟踪的宏观日历]

### L2 政策与制度
[近3-6个月关键政策事件时间线;未来可预见的政策催化剂]

### L3 中观行业(如适用)
[行业生命周期定位;估值分位区间;核心风险点1-3条]

### L4 市场交易结构与情绪
[当前情绪周期定性判断;短期流动性风险提示]

### L5 微观个股(如适用)
按6个子块分别陈述,每块给出具体异常项而非笼统结论:
- 财务风险:[具体异常科目及数值]
- 公司治理风险:[具体异常项]
- 经营风险:[具体异常项]
- 估值风险:[相对历史/行业分位情况]
- 特殊/事件性风险:[见上方红旗信号清单,此处可简要引用]
- 技术面/交易层面(辅助):[粗略定性描述,注明数据来源是
  ashare-technical-analysis打分还是简化定性]

## 四、系统性风险 vs 非系统性风险

- **系统性风险**(需靠仓位管理/对冲应对,无法通过选股规避):
  [列出属于L1/L2/L4的风险点]
- **非系统性风险**(可通过分散持仓/精选标的降低):
  [列出属于L5个股自身的风险点]
- [如为持仓组合,补充组合层面的行业集中度/相关性风险提示]

## 五、数据来源与缺口说明

- 本次分析使用的数据来源:[专业金融MCP / 相关ashare-skill产出 /
  通用网络检索 / 用户提供资料,如实注明]
- 数据缺口:[哪些层面因数据源限制未能充分展开,如实列出,不要假装
  已完整覆盖]

## 六、风险提示与免责声明

本报告基于截至[日期]可获得的公开信息与检索结果生成,仅用于帮助梳理
投资风险认知,**不构成买入、卖出或持有的投资建议**。风险等级为定性
判断,不是精确预测;宏观、政策、市场类信息存在时效性,如报告生成后
有较长时间才使用,建议先确认是否有需要更新的重大变化。最终投资决策
及其风险应由投资者结合自身风险承受能力自行判断和承担。
```

## 撰写原则补充

- **速览表要能让用户3秒内抓住重点**——总体风险等级和是否命中红旗
  信号,应该是全篇最先看到、最不会漏看的信息。
- **矛盾要明说,不要和稀泥**:如果L1-L4显示系统性风险较低,但L5命中
  个股层面的严重问题(或反之),要明确指出这种分层之间的矛盾,并
  说明这对总体结论的影响,而不是简单取一个折中的"中风险"敷衍过去。
- **止损/减仓等操作性建议不属于本报告范围**——如果用户在看完风险
  报告后进一步询问具体操作,应引导其结合自身仓位和风险承受能力
  判断,或視情況建议结合`ashare-technical-analysis`获取止损位参考,
  而不是在这份风险报告里直接给出操作指令。
