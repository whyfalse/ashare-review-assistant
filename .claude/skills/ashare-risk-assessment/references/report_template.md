# 风险评估报告模板

撰写最终报告时,以此结构为骨架,用L1-L6的判断结果填充,**不要把检索字段原样罗列成流水账**——每层都要落到"这意味着什么风险"的判断性文字,而不是停在"某指标是多少"的事实陈述。

```markdown
# [分析对象]投资风险评估报告

**分析对象**:[大盘 / XX行业板块 / XX股票代码及名称 / 持仓组合]
**分析范围**:[覆盖的层级,如"L1+L2+L4" 或 "L1-L6全部"]
**数据截止日期**:[明确标注,风险信息有时效性]

## 一、风险速览

| 层面 | 风险等级 | 核心结论(一句话) |
|---|---|---|
| L1 宏观环境 | 低/中/高 | ... |
| L2 政策与制度 | 低/中/高 | ... |
| L3 中观行业(如适用) | 低/中/高 | ... |
| L4 市场交易结构与情绪 | 低/中/高 | ... |
| L5 微观个股(如适用) | 低/中/高 | ... |
| **总体风险等级** | **低/中/高** | [是否命中一票否决红旗需在此注明] |

## 二、红旗信号清单(如有,置顶单独展示)

> L5.5 命中任何一票否决级红旗(ST/立案调查/审计非标/股权冻结/海外制裁等)必须在此单独列出,说明这是总体结论定为"高风险"的直接原因,不能被其他层面正面信息稀释。未命中时注明"未发现一票否决级别的红旗信号"。
>
> 与历史红旗对照:本清单必须包含步骤0.2从 `data/risk_flags.json` 读出的该对象 `status=open` 红旗的本次核实结果——持续(自 YYYY-MM-DD 起)/新增/已解除(依据:...),不要默默删除。

- [红旗1]:[具体内容 + 发现日期/来源 + 状态(持续/新增/已解除)]
- [红旗2]:...

## 三、分层详细分析

### L1 宏观环境
[国内经济周期阶段判断的文字论述,引用支撑判断的关键数据点;**全球宏观外溢方向(正/中/负+传导渠道)**,叠加全球维度横切;需跟踪的国内及全球宏观日历]

### L2 政策与制度
[近3-6个月关键政策事件时间线(附日期);未来可预见催化剂;**海外政策外溢提示(如适用,标注主要受影响环节与传导渠道)**]

### L3 中观行业(如适用)
[行业生命周期定位;估值分位区间;核心风险点1-3条;**海外敞口风险提示(如适用,叠加全球维度横切)**]

### L4 市场交易结构与情绪
[当前情绪周期定性判断;短期流动性风险提示;**全球风险偏好对国内的传导方向(如适用,叠加全球维度横切)**]

### L5 微观个股(如适用)
按6个子块分别陈述,每块给出具体异常项而非笼统结论:
- 财务风险:[具体异常科目及数值]
- 公司治理风险:[具体异常项]
- 经营风险:[具体异常项,含**海外业务敞口(海外营收占比/汇率敞口/跨境供应链)**]
- 估值风险:[相对历史/行业分位情况]
- 特殊/事件性风险:[见上方红旗信号清单,此处简要引用;含**海外制裁/实体清单/重大海外诉讼/海外退市审计/反倾销反补贴**等海外维度红旗]
- 技术面/交易层面(辅助):[粗略定性描述,注明数据来源是 `ashare-technical-analysis` 打分还是简化定性]

## 四、系统性风险 vs 非系统性风险

- **系统性风险**(需靠仓位管理/对冲应对,无法通过选股规避):
  [列出属于L1/L2/L4的风险点,含全球系统性风险外溢,并标注当前是否触发L6的"全球系统性风险叠加规则"]
- **非系统性风险**(可通过分散持仓/精选标的降低):
  [列出属于L5个股自身的风险点,含个股层面海外业务/汇率/制裁敞口]
- [如为持仓组合,补充组合层面的行业集中度/相关性风险提示]

## 五、数据来源与缺口说明

### 数据来源(与启动前取数计划表逐桶核对,事后填报)

| 数据大类 | 涵盖桶 | 来源工具(tool_id) | 实际层级(primary/fallback) | 备注 |
|---|---|---|---|---|
| 宏观指标 | `macro_indicator` | <填配置 tool_id> | primary / fallback(写明 error.code) | |
| 政策与公告资讯 | `news_policy` + `announcement_doc` | <填配置 tool_id> | primary / fallback | **此行必须含 primary 工具,仅 web_search 时须注明"未经专业资讯源交叉核对"** |
| 基本面与估值 | `cn_equity_fundamental` + `cn_equity_quote` | <填配置 tool_id> | primary / fallback | |
| 市场结构 / 技术面 / 全球跨资产 | `fund_index_bond` + `cn_tech_daily`(复用) + 全球宏观与跨资产(扩展) | <填配置 tool_id 或 复用 ashare-macro-context / ashare-technical-analysis> | primary / fallback / 复用 | L5.6 注明是引用技术打分还是简化定性;全球维度若走 web_search 须注明"未经专业源交叉核对" |

核对规则:每行的"来源工具"与"层级"必须与启动前取数计划表一致;若实际走了 fallback,备注列必须写明 primary 失败的 error.code。政策资讯一行若不含配置 primary 工具,视为未完成交叉印证,须显式声明可靠性局限。

### 数据缺口

[哪些层面因数据源限制未能充分展开,如实列出,不要假装已完整覆盖;用户直接提供资料的部分注明来源。]

## 六、风险提示与免责声明

本报告基于截至[日期]可获得的公开信息与检索结果生成,仅用于帮助梳理投资风险认知,**不构成买入、卖出或持有的投资建议**。风险等级为定性判断,不是精确预测;宏观、政策、市场类信息存在时效性,如报告生成后有较长时间才使用,建议先确认是否有需要更新的重大变化。最终投资决策及其风险应由投资者结合自身风险承受能力自行判断和承担。
```

## 撰写原则补充

- **速览表要能让用户3秒内抓住重点**——总体风险等级和是否命中红旗信号,应该是全篇最先看到、最不会漏看的信息。
- **矛盾要明说,不要和稀泥**:如果L1-L4显示系统性风险较低,但L5命中个股层面的严重问题(或反之),要明确指出这种分层之间的矛盾,并说明这对总体结论的影响,而不是简单取一个折中的"中风险"敷衍过去。
