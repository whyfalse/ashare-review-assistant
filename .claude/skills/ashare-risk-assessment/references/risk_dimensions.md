# 六层风险框架完整维度表

版本:v1.0(首次创建)。本文件是SKILL.md六层框架的详细展开,包含完整
检索字段、判断阈值/红旗信号、输出指标三部分。数值阈值均为**经验参考
区间**,不是精确科学结论,不同行业、不同市场环境下应结合实际情况调整,
不要机械套用。

> 使用提示:不需要每次分析都逐字段核对一遍。先看SKILL.md里每层的概览,
> 只有在需要确认"这个数值算不算高风险"或"这层到底该查哪些字段"时,
> 再来查对应小节。

---

## L1 宏观环境风险

| 检索字段 | 判断标准/红旗信号 |
|---|---|
| GDP增速(季度同比) | 连续2个季度环比放缓,提示经济动能减弱 |
| PMI(制造业/非制造业) | 荣枯线50为分界;连续3个月以上低于50提示收缩风险 |
| 社会消费品零售总额同比 | 增速持续低于名义GDP增速,提示内需偏弱 |
| 规模以上工业增加值 | 结合PMI交叉验证,避免单一指标误判 |
| MLF/LPR利率变动 | 连续下调提示货币宽松;连续上调或维持高位提示收紧 |
| 社融存量增速 vs 名义GDP增速 | 剪刀差持续为负(社融增速低于名义GDP增速)提示信用收缩 |
| M1-M2剪刀差 | 走阔提示企业活期资金活跃、流动性改善;持续收窄或为负提示经济活力不足 |
| 人民币汇率(兑美元) | 单月贬值超2%-3%需关注资本外流压力;需同时看外汇储备变化交叉验证 |
| 北向资金月度净流向 | 连续2-3个月净流出,提示外资对A股/特定行业的偏好转弱 |
| CPI同比 | 持续低于1%提示通缩压力;持续高于3%提示通胀压力,可能制约货币宽松空间 |
| PPI同比 | 连续多月(6个月以上)负增长,提示工业品价格通缩,挤压中下游企业利润 |
| 房地产销售面积/金额同比 | 连续两位数下滑,警惕地产链条对信用扩张和相关产业的拖累 |
| 中美关系动态 | 关税/出口管制/高层会晤等事件性变化,需标注具体日期,避免用旧消息 |
| 美联储利率路径 | 加息周期尾声/降息预期变化会显著影响全球风险资产估值和北向资金行为 |

**输出**:风险等级(低/中/高)+ 一句话理由;经济周期阶段判断(扩张/
复苏/滞胀/衰退,四选一,拿不准时说明"处于过渡阶段,信号不清晰");
未来1-3个月需跟踪的宏观数据发布/会议日历(如下一次统计局数据发布、
央行议息会议日期)。

## L2 政策与制度风险(A股特有)

| 检索字段 | 判断标准/红旗信号 |
|---|---|
| IPO/再融资节奏 | 节奏骤然加快,提示扩容压力,对存量资金有分流效应 |
| 退市新规执行力度 | 近期退市案例数量/涉及行业变化,提示监管对"壳资源"炒作的态度 |
| 注册制细则调整 | 关注是否扩大适用范围或收紧审核标准 |
| 监管机构公开表态 | 证监会/央行/发改委等近期表态中,是否点名特定行业或交易行为 |
| 行业专项监管整治 | 分析对象所在行业是否有密集发文、约谈、专项检查 |
| 交易规则变动 | 涨跌停幅度、T+1、融资融券规则、股份减持规则等调整 |
| 头部公司监管动态 | 行业龙头是否被立案调查/处罚,往往是行业性收紧的先兆信号 |

**红旗信号**:短期内(1-2个月)同一行业连续出现2次以上监管发文或
处罚案例;交易规则发生非常规临时性调整(如临时性的融券限制)。

**输出**:政策风险等级 + 近3-6个月关键政策事件时间线(需附具体日期)
+ 可预见的未来政策催化剂(已排期的会议、征求意见稿落地时点等)。

## L3 中观行业/板块风险

| 检索字段 | 判断标准/红旗信号 |
|---|---|
| 行业生命周期阶段 | 导入期(高不确定性)/成长期/成熟期(格局稳定)/衰退期(警惕) |
| 行业集中度(CR3/CR5) | 集中度过低且持续下降,提示价格战风险;需结合具体行业判断 |
| 供需/库存周期位置 | 主动补库存(景气上行)/被动补库存(景气见顶)/主动去库存(景气下行)/被动去库存(景气见底) |
| 产能利用率 | 持续低于70%-75%(制造业经验参考值)提示产能过剩风险 |
| 行业估值历史分位数 | 处于自身历史80%分位以上,警惕估值过高;20%以下需结合基本面判断是否为预期差机会 |
| 行业相对全市场估值分位 | 交叉验证,避免"绝对低估但相对更贵"的误判 |
| 技术替代风险 | 是否存在正在快速渗透的替代技术/产品(如传统能源vs新能源) |
| 政策依赖度 | 净利润中补贴/税收优惠占比过高(如超过30%),政策退坡时业绩弹性大 |

**输出**:行业风险等级 + 估值所处历史分位区间(数值区间,如"处于近
5年60%-70%分位") + 核心风险点(1-3条,避免面面俱到罗列所有可能性)。

## L4 市场交易结构与情绪风险

| 检索字段 | 判断标准/红旗信号 |
|---|---|
| 全市场PE/PB历史分位数 | 高于80%分位提示估值整体偏贵;低于20%提示整体偏便宜,但需结合盈利趋势 |
| 融资融券余额变化趋势 | 短期(1-2周)快速攀升,提示杠杆资金入场加速,情绪升温但踩踏风险也上升 |
| 北向资金短期流向 | 与L1的中期流向趋势交叉验证,区分"短期波动"和"趋势性变化" |
| 新发基金规模 | 单月新发规模处于历史高位区间,往往对应情绪亢奋期后段 |
| 涨跌停家数比 | 涨停家数远超跌停家数且持续多日,提示情绪过热;反之提示恐慌 |
| 市场平均换手率 | 处于历史高位区间,配合涨跌停家数比判断是否为情绪顶部信号 |
| 量化/程序化交易占比 | 占比上升可能放大极端行情下的波动率和流动性风险 |

**红旗信号**:融资余额快速攀升 + 涨跌停家数比严重失衡 + 换手率历史
高位,三者同时出现,是情绪过热、后续回调风险上升的组合信号。

**输出**:市场情绪风险等级 + 当前情绪周期定性判断(冰点/修复/亢奋/
退潮,或说明处于过渡阶段) + 短期流动性风险提示。

## L5 微观个股风险(六个子块)

### 5.1 财务风险

| 检索字段 | 判断标准/红旗信号 |
|---|---|
| 资产负债率 | 制造业超过70%需警惕;需结合行业特性(如金融、地产天然高杠杆)判断 |
| 有息负债规模及占比 | 有息负债占总负债比例过高且短期偿债压力大(短期借款+一年内到期非流动负债 vs 货币资金) |
| 流动比率/速动比率 | 速动比率长期低于1,提示短期偿债能力偏弱 |
| 经营性现金流 vs 净利润 | 经营现金流连续2年为负但净利润为正("纸面富贵"),是重大红旗,需重点展开 |
| 应收账款/存货增速 vs 营收增速 | 应收账款或存货增速显著快于营收增速(如快1倍以上),警惕收入质量或存货减值风险 |
| 商誉占净资产比例 | 超过30%警惕并购标的业绩不及预期导致的减值风险 |

### 5.2 公司治理风险

| 检索字段 | 判断标准/红旗信号 |
|---|---|
| 前十大股东股权质押比例 | 控股股东质押比例超过50%,叠加股价下跌时警惕平仓风险 |
| 限售股解禁时间表 | 近期(1-3个月内)是否有大规模解禁,规模占流通股比例是否显著 |
| 实控人/高管增减持记录 | 近6个月是否有密集减持,尤其是在业绩公告前后的减持需重点关注 |
| 审计意见类型 | 保留意见/无法表示意见/否定意见,属于重大红旗,必须单独highlight |
| 关联交易占比 | 关联交易占营收/采购比例过高,警惕利益输送风险 |

### 5.3 经营风险

| 检索字段 | 判断标准/红旗信号 |
|---|---|
| 前五大客户/供应商集中度 | 集中度过高(如前五大客户占比超过50%)且客户关系无长期协议保障 |
| 主营收入增速 vs 行业平均 | 显著低于行业平均,警惕份额流失;显著高于行业平均则需核实是否可持续 |
| 政府补贴占净利润比例 | 比例过高(如超过50%),扣除补贴后可能实际亏损 |
| 管理层近期变动 | 核心高管(尤其是财务负责人)非正常离职,是需要关注的信号 |

### 5.4 估值风险

| 检索字段 | 判断标准/红旗信号 |
|---|---|
| PE/PB/PEG相对自身历史分位 | 高于80%历史分位,警惕估值透支未来增长 |
| PE/PB相对行业分位 | 显著高于行业平均且缺乏明确的基本面支撑理由 |
| 近期涨幅 vs 基本面变化 | 短期(如1个月)涨幅远超同期基本面/业绩指引变化幅度,提示题材炒作特征 |

### 5.5 特殊/事件性风险(一票否决级别)

| 检索字段 | 判断标准/红旗信号 |
|---|---|
| ST/\*ST状态 | 命中即为高风险信号,需在结论中显著提示 |
| 未决重大诉讼 | 涉案金额相对公司净资产/净利润的比例,判断潜在影响程度 |
| 监管立案调查/行政处罚 | 命中即为高风险信号,尤其是涉及财务造假、信息披露违规的调查 |
| 股权冻结 | 控股股东股权被大比例冻结,警惕控制权变更或流动性危机风险 |
| 重大舆情 | 近期是否有产品质量、安全生产等重大负面舆情事件 |

**这一子块的判断原则与其他子块不同**:只要命中上述任一红旗,不论
其他子块表现多好,都必须在最终结论中单独、显著地提示为"高风险/
需谨慎",不能被平均掉、稀释掉。

### 5.6 技术面/交易层面风险(辅助,非决定性)

优先复用`ashare-technical-analysis`的打分结果。没有该skill时只做
粗略定性描述:近期是否放量下跌、股价是否跌破关键均线(如年线)、
是否有明显的技术性破位信号。**这一子块只作为参考,不应单独决定
整体结论**——技术信号和基本面/事件性风险冲突时,以基本面和事件性
风险的判断为准。

## L6 风险综合判断规则

1. **先看5.5是否命中任何红旗**——命中则总体结论直接定为"高风险/
   需谨慎",跳过后续加权步骤,在报告中用醒目方式单独列出命中的具体
   红旗项。
2. **未命中5.5红旗时**,综合L1-L4(系统性风险层面)和5.1-5.4(个股
   非系统性风险层面)的风险等级分布做定性判断,而不是做精确加权
   平均——如果多数层面为"中"或以上,总体倾向"中风险";如果L1-L4
   多层同时为"高"(比如宏观滞胀+政策收紧+市场情绪过热同时出现),
   即使个股层面尚可,也应提示系统性风险主导,总体结论不应低于"中高"。
3. **持仓组合额外检查**:统计组合内个股在行业/风险因子上的集中度,
   如果多只个股集中在同一受政策/周期影响的行业,即使单只个股风险
   都不高,也要在报告中提示组合层面的集中度风险,并说明这是L6的
   延伸判断,不是重新计算了某只个股的风险等级。
