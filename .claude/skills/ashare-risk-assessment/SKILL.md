# A股投资风险全面评估

## 适用边界(Scope)

本skill遵守 `../../../references/boundaries.md` 的全部共享边界，正文不再逐条复述。以下仅列本skill特有边界：

1. **风险等级是"风险信息",不是"操作指令"**:本skill产出的是分层风险等级与依据,最终仓位决策权在用户。即使用户追问"那到底能不能买",也应引导其结合自身风险承受能力与仓位管理原则自行决定,不替用户拍板;用户情绪化(被套/急于找理由加仓)时尤其不能用更确定的语言去迎合(共享边界 §2 的强化口径)。
2. **只给风险等级(低/中/高)与方向性判断,不做精确预测**:任何看起来过于精确的百分比/点位预测都应改写为区间或定性判断(共享边界 §2)。
3. **不重复造轮子**:宏观长期记忆复用 `ashare-macro-context`、技术打分复用 `ashare-technical-analysis`,不重新建库、不重算指标(复用细节与路径见下文"与其他ashare-*skill及项目内MCP的关系")。
4. **不硬编码数据源**:本skill只规定"需要哪类信息"和"这类信息该怎么判断",具体用哪个工具取数由 `data-source-config.json` 的 `routing` 决定(流程见 `../../../references/data-source-priority.md`),不在本文件里写死任何工具名/API/MCP。

## 这个skill做什么

按照"宏观→制度→中观→市场→微观"的层次,系统盘点一个分析对象
(大盘/板块/个股/持仓组合)面临的投资风险,对每个层面回答三个问题——
**要查什么、怎么判断高低、输出什么**——最终产出一份分层的风险清单和
总体风险等级,帮助用户在做买卖决策前建立完整的风险认知。

## 与其他ashare-*skill及项目内MCP的关系

- **`ashare-macro-context`**:如果本地存在其维护的宏观记忆文件
  (`../../../data/macro_context.json`),做L1/L2层时优先直接读取复用其中
  相关维度的`summary`,不要重新检索一遍;没有该skill或记忆文件为空时,
  本skill自行按需做一次轻量检索即可,不必反过来帮它建库(建库不是本skill的职责)。
  引用其内容时按共享边界 §5 口径,明确告知是"环境背景校准",不替代短期买卖
  时点判断;若某条 `next_review_due` 已严重过期,提示用户先更新再用。
- **`ashare-technical-analysis`**:其打分结果(五维度分数、结论、止损/目标位)
  直接作为L5.6"技术面/交易层面"的输入,不重算指标;无该skill时L5.6只做粗略
  定性并注明简化(详见L5.6)。
- **数据获取工具**(行情、财报、公告、新闻舆情、宏观指标类MCP/脚本):
  不在本文件硬编码——取数前读 auto-memory 的 `data-source-config.json`,
  按 `../../../references/data-source-priority.md` 的桶路由与"取数计划表 gate"
  选择工具(详见下文"取数准备")。
- 没有以上任何辅助资源时,本skill仍然可以独立运行——退化为"通用网络
  检索 + 如实告知数据局限性",而不是拒绝分析。

## 步骤0:确定分析对象与需要覆盖的层级

不同分析对象需要跑的层级不同,先确认用户到底想分析什么,避免小题大做
或遗漏关键层面:

| 分析对象 | 需要覆盖的层级 |
|---|---|
| 大盘/市场整体 | L1宏观 + L2政策制度 + L4市场交易结构与情绪 + L6综合 |
| 某个行业/板块 | L1(仅相关部分)+ L2(该行业相关政策)+ L3中观行业 + L4(该板块资金/情绪)+ L6 |
| 具体个股 | L1-L5全部展开 + L6;其中L1/L2若已有大盘层级结论可直接引用,不必重复展开 |
| 已持仓组合(多只个股) | 对组合内每只股票分别跑L5,再叠加组合层面的集中度/相关性风险(见L6最后一小节) |

如果用户的提问比较模糊(比如只说"最近风险大不大"),默认按"大盘整体"
处理;如果给出了具体股票代码或名称,按"具体个股"展开到L5。拿不准时,
用一句话跟用户确认分析范围,而不是自行猜测后跑错层级浪费检索。

**本地输入**:分析"已持仓组合"时,持仓清单从 `../../../data/positions.json`
读取(不要凭记忆假设持仓);自选股从 `../../../data/watchlist.json` 读取。
文件不存在时提示用户先用对应skill/template建立,不要凭空编造持仓。

## 取数准备(启动前 gate,未完成不得进入L1取数)

> 按 `../../../references/data-source-priority.md` 的"取数前配置准备"流程:先读 auto-memory 的 `data-source-config.json` 并做轻量校验;配置缺失或校验失败(关键专业工具消失/依赖缺失/`next_review_due` 过期/`version<2` 旧结构)时,先接力调用 `ashare-data-source-config` 重新编排,再开始取数。本skill不硬编码任何工具名——工具选择全部由配置 `routing` 决定。**取数过程中记录每类数据实际使用的工具(primary 还是 fallback),供末尾"数据来源"小节使用。**

> 财经媒体(只采信定性信息,精确数字注明未经专业源核对);仍不可得时要求用户提供

## 六层风险框架

完整的检索清单、判断阈值、红旗信号表见 `references/risk_dimensions.md`
——首次使用,或不确定某层具体要查什么字段、什么数值算高风险时,
务必先读这个文件,不要凭记忆假设阈值。下面是每层的概览。

### L1 宏观环境风险

**要检索的内容**:
- **国内**:GDP/PMI/社零/工业增加值等经济景气数据及其近3-4个季度
  走势(不只看单月快照)、货币政策基调与MLF/LPR利率变动、社融存量增速与
  M1-M2剪刀差、人民币汇率走势及外资(北向)月度资金流向、CPI/PPI同比、
  房地产销售与房企融资环境。
- **全球(外溢到国内的部分)**:美国/欧元区/日本等主要经济体的景气
  走势与货币政策路径(美联储/欧央行/日央行议息节奏)、美元指数(DXY)
  与美债收益率走势、中美利差(10Y)及其对人民币汇率的传导、CRB/原油/
  铜/铁矿石等大宗商品价格趋势、全球地缘政治动态(俄乌/中东/中美/台海
  等,不只看中美)、全球贸易景气(BDI/出口型经济体出口增速)。

**怎么判断**:国内周期判断同前(PMI荣枯线、社融与名义GDP增速剪刀差、
M1-M2剪刀差);汇率短期(如1个月内)贬值超过2%-3%需要关注资本外流压力。
**全球视角的叠加判断**:①主要央行同步收紧(加息或缩表)往往压制全球
风险偏好,新兴市场外资流出压力上升;②美元指数与美债收益率同步上行
通常对A股估值(尤其成长股)和北向资金构成压力;③中美10年期利差倒挂
且持续走阔,提示人民币贬值与资本外流压力;④原油/铜等大宗异动往往是
全球需求或地缘风险的领先信号;⑤多区域地缘风险共振(如同时出现俄乌
+中东+中美紧张)需上调系统性风险等级。更多红旗信号(如PPI连续多月
负增长、地产销售同比连续两位数下滑、外资连续多月净流出)见references
文件。

**要输出的内容**:宏观风险等级(低/中/高)+一句话理由、当前国内经济
周期阶段判断、**全球宏观环境对国内的外溢方向(正面/中性/负面+主要
传导渠道)**、未来1-3个月需要重点跟踪的国内及全球宏观数据/事件日历
(如美联储议息、美国非农/CPI、欧央行决议、地缘事件节点)。

### L2 政策与制度风险(A股特有)

**要检索的内容**:IPO/再融资节奏与规则变化、退市新规与执行力度、
注册制相关细则调整、证监会/央行/发改委等监管机构近期公开表态、
分析对象所在行业是否有专项监管整治、交易规则变动(涨跌停幅度、
T+1、融资融券规则等)、**海外政策外溢**(美国关税/出口管制/对华
投资限制、欧盟碳关税与产业政策、海外上市审计与退市规则、主要贸易
伙伴反倾销调查等对国内出口链与相关板块的传导)。

**怎么判断**:重点识别"政策转向"信号——某个方向从鼓励转为限制,或
反之;监管层近期是否对该行业/该类操作有过公开警示或密集发文;
是否有头部公司被立案调查/约谈,这类事件往往是行业性监管收紧的先兆。
**海外政策外溢**需结合分析对象的海外营收占比与产业链位置判断传导
强度:海外营收占比高、终端市场在限制清单内的,传导为直接冲击;
仅上游原料/中游代工环节暴露的,传导较间接但仍有定价权侵蚀。

**要输出的内容**:政策风险等级 + 近3-6个月关键政策事件时间线 +
可预见的未来政策催化剂(如已排期的会议、征求意见稿的落地时点)+
**海外政策外溢风险提示(如适用,标注主要受影响环节与传导渠道)**。

### L3 中观行业/板块风险

**要检索的内容**:行业所处生命周期阶段(导入/成长/成熟/衰退)、行业
集中度和竞争格局、供需与库存周期数据、行业整体估值水平(相对自身
历史分位数 + 相对全市场分位数)、是否存在技术替代风险、对补贴/牌照/
关税等政策的依赖程度。**全球视角**:行业海外营收占比与主要出口目的
地分布、在全球产业链中的位置(上游资源/中游制造/下游品牌)、是否受
关税/出口管制/反倾销影响、海外竞品格局与全球产能周期(全球同步
扩产往往引发过剩)。

**怎么判断**:估值历史分位数处于80%以上需要警惕估值过高风险,处于
20%以下则提示可能存在预期差机会(但仍需结合基本面,不能仅凭低估值
判断风险低);产能利用率持续走低提示产能过剩;行业景气度领先指标
(出口数据、开工率、库存周期位置)连续走弱是中期风险信号。**海外
敞口判断**:海外营收占比超过30%且主要目的地出现关税/管制/反倾销
政策时,需单列外溢风险;全球产能同步扩张(如新能源/光伏/电动车
链条历史案例)即使国内格局稳定,也面临海外价格战与产能出清风险。

**要输出的内容**:行业风险等级 + 估值所处历史分位区间 + 该行业当前
核心风险点(列1-3条,不要面面俱到罗列所有可能性)+ **海外敞口风险
提示(如适用,标注主要受影响的海外市场与传导渠道)**。

### L4 市场交易结构与情绪风险

**要检索的内容**:全市场PE/PB历史分位数、融资融券余额及其变化趋势、
北向资金短期(周/月)净流向、新发基金规模、涨跌停家数比、市场平均
换手率、量化/程序化交易占比的相关信息。**全球风险偏好与跨资产
联动**:VIX指数及其期限结构、美债10年期收益率与中美10年期利差、
美元指数(DXY)短期走势、A股与标普500/恒生指数/新兴市场指数的短期
相关性变化、黄金/原油等避险或风险资产表现。

**怎么判断**:融资余额短期快速攀升同时涨跌停家数比明显失衡,提示
情绪过热、存在踩踏风险;北向资金连续净流出叠加市场估值处于高位,
提示估值和流动性双重压力;换手率和新发基金规模同时处于历史高位区间
往往对应情绪亢奋期,后续回调风险上升。**全球联动判断**:VIX飙升至
20以上且持续高位,往往伴随全球风险资产共振回调,北向资金外流压力
上升;中美利差深度倒挂(如美债收益率高于中债100bp以上)叠加美元走强,
是外资减持A股的典型组合;A股与美股相关性短期内急剧抬升,提示当前
受全球系统性因子主导,国内政策对冲效果可能被削弱。

**要输出的内容**:市场情绪风险等级 + 当前所处情绪周期定性判断
(冰点/修复/亢奋/退潮,四选一或说明处于过渡阶段)+ 短期流动性风险提示
+ **全球风险偏好对国内的传导方向(如适用)**。

### L5 微观个股风险(仅当分析对象为具体个股/持仓组合中的个股时展开)

这一层再拆成六个子块,每个子块都要检索、判断、输出,完整字段清单和
阈值在references文件里,这里给出每块的核心逻辑:

- **财务风险**:查资产负债率、有息负债规模、经营性现金流与净利润
  的匹配度、应收账款/存货增速是否显著快于营收增速、商誉占净资产
  比例。经营性现金流连续两年为负但净利润为正("纸面富贵")、商誉
  占净资产超过30%,都是需要重点展开说明的异常信号,不是随口一提。
- **公司治理风险**:查前十大股东股权质押比例、限售股解禁时间表和
  规模、实控人/高管近6个月增减持记录、审计意见是否非标(保留意见/
  无法表示意见)、关联交易占比。质押比例过高(尤其叠加股价下跌)会
  带来平仓风险;审计意见非标是重大红旗,必须单独highlight,不能被
  其他维度的正面信息稀释。
- **经营风险**:查前五大客户/供应商集中度、主营收入增速相对行业
  平均的位置、净利润对政府补贴的依赖程度、管理层近期是否有非正常
  变动。**海外业务敞口**:海外营收占比及主要地区分布、是否依赖海外
  关键客户或单一地区、汇率波动对毛利率/财务费用的影响(是否有套保)、
  跨境供应链关键环节(芯片/设备/原料)是否受制于单一海外供应商。
- **估值风险**:查PE/PB/PEG相对自身历史分位数和相对行业分位数、
  近期涨幅是否明显脱离基本面变化(题材炒作特征)。
- **特殊/事件性风险**:查是否ST/\*ST、是否有未决重大诉讼、是否被
  监管立案调查或行政处罚、股权是否被冻结、近期是否有重大舆情。
  **海外维度**:是否在美/欧/港等海外市场被列入出口管制/实体清单/
  制裁名单、是否有海外重大诉讼(专利/反垄断/集体诉讼)、是否面临
  海外退市或审计争议、是否被加征反倾销/反补贴税。
  **这一类本质上是一票否决式的红旗**——只要命中,不论其他层面多好看,
  都要在最终结论里单独、显著地提示,不能被平均掉。
- **技术面/交易层面(辅助)**:如果本地有`ashare-technical-analysis`
  的打分结果,直接引用其结论作为这里的输入;否则只做粗略定性描述
  (比如近期是否放量下跌、是否跌破关键均线),并明确说明这是简化
  版本,不追求精细化,更不要越俎代庖去重新计算一遍技术指标。

**要输出的内容**:六个子块各自的风险等级 + 具体异常项列表(哪个科目/
哪个指标异常,不要只给"财务风险:中"这种无信息量的结论)。

### L6 风险综合与分类输出

把L1-L5识别出的风险点归类为两大类:

- **系统性风险**:无法通过精选个股规避,只能靠仓位管理/对冲应对
  (如L1宏观周期、L2政策转向、L4市场情绪踩踏、**全球系统性风险外溢
  如美联储激进加息/全球地缘冲突/美债收益率急升**)。
- **非系统性风险**:可以通过分散持仓、精选标的降低(主要来自L5
  个股自身的财务/治理/经营问题,包括个股层面的海外业务/汇率/制裁敞口)。

**总体风险等级的判断遵循"红旗信号优先于加权平均"的原则**:如果L5命中
任何"特殊/事件性风险"红旗(ST、立案调查、审计非标等),无论其他层面
表现多好,总体结论都必须标注为"高风险/需谨慎",不能因为其他维度分数
不错就把这个红旗平均掉、稀释掉——这一点类似`ashare-technical-analysis`
里"风险否决规则"的思路。如果分析对象是持仓组合,还要额外检查组合内
个股之间的行业集中度和相关性,过度集中在同一行业/同一风险因子上,
即使单只个股风险都不高,组合层面的风险也可能被低估。

**全球系统性风险叠加规则**:当L1(全球宏观)、L2(海外政策外溢)、L4
(全球风险偏好)三个层面的全球维度同时出现"高风险"信号——典型组合如
"主要央行同步收紧 + 美元与美债收益率同步上行 + VIX飙升至20以上"——
即使国内层面(L1国内/L2国内/L5)仅为中风险,总体结论也应上调一档
(由"中"上调为"中高",由"中高"上调为"高"),并在报告中明确指出这是
全球系统性因子主导、国内政策对冲空间受限的情境。单层全球维度为高、
其他不共振时,不上调总体等级,但在报告中标注"需重点跟踪该维度是否
演化为全球共振"。

**区分结构性风险与事件性风险**:结构性风险是慢变量(如行业生命周期阶段、
全球产业链重构),不会因一两天没有新消息而改变;事件性风险必须标注
具体日期,避免把过时旧闻当成新催化剂讲。

## 撰写最终报告

按 `references/report_template.md` 的固定结构输出,核心是:分层风险
速览表(一眼看出哪层风险高)+ 分层详细说明 + 红旗信号清单(如有,单独
置顶)+ 数据来源与缺口说明 + 风险提示与免责声明。不要把六层的检索
字段原样罗列成流水账,要对每层给出有判断力的文字结论(参照L1-L6的
"怎么判断"部分动笔),并在各层结论互相矛盾时明确指出矛盾本身,而不是
挑顺眼的层面强调、弱化不顺眼的层面。

`../../../output/ashare-risk-assessment/` 文件夹下。文件名按分析对象:

- 个股:`<标准代码>_risk_[日期].md`(代码去掉点号,如 `600519SH_risk_2026-07-01.md`)
- 大盘/板块/组合:`risk_<对象简述>_[日期].md`(如 `risk_大盘_2026-07-01.md`、
  `risk_持仓组合_2026-07-01.md`)

(同一对象同一天重复分析以最新一次为准)。
