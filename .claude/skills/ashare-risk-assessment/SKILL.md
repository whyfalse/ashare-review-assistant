# A股投资风险全面评估

## 适用边界(Scope)

本skill遵守 `../../../references/boundaries.md` 的全部共享边界,正文不再逐条复述。本skill特有边界:

1. **风险等级是"风险信息",不是"操作指令"**:只给低/中/高风险等级与方向性判断,不做精确百分比/点位预测;最终仓位决策权在用户。用户情绪化(被套/急于加仓)时尤其不能用更确定的语言去迎合。
2. **不硬编码数据源**:本skill只规定"需要哪类信息"和"该怎么判断",具体用哪个工具取数由 `data-source-config.json` 的 `routing` 决定(流程见 `../../../references/data-source-priority.md`),不在本文件写死任何工具名/API/MCP。

## 这个skill做什么

按照"宏观→制度→中观→市场→微观"的层次,系统盘点一个分析对象(大盘/板块/个股/持仓组合)面临的投资风险,对每个层面回答三个问题——**要查什么、怎么判断高低、输出什么**——最终产出一份分层的风险清单和总体风险等级。

## 与其他skill及项目内MCP的关系

- **`ashare-macro-context`**:做L1/L2时优先读取其维护的 `../../../data/macro_context.json` 中相关维度的 `summary` 复用,不重新检索;文件为空或某条 `next_review_due` 严重过期时,提示用户先更新再用,不反过来帮它建库。
- **`ashare-technical-analysis`**:其打分结果(五维度分数、结论、止损/目标位)直接作为L5.6"技术面"的输入,不重算指标;无该skill时L5.6只做粗略定性并注明简化。
- **红旗信号长期记忆**(`../../../data/risk_flags.json`):记录历史分析中发现、尚未解除的一票否决级红旗(ST/立案/审计非标/股权冻结/重大诉讼/海外制裁/反倾销等)。**本skill是该文件的唯一写入者**,其他技能只读不写。分析启动前读取 `status=open` 的红旗作为必查项(本次必须重新核实),分析结束后回写(详见"输出与回写")。
- 没有以上任何辅助资源时,本skill仍可独立运行——退化为"通用网络检索 + 如实告知数据局限性",而不是拒绝分析。

## 步骤0:启动前检查

进入L1取数前依次完成三件事:

### 0.1 确认分析对象与覆盖层级

不同对象需要跑的层级不同,先确认避免小题大做或遗漏:

| 分析对象 | 覆盖层级 |
|---|---|
| 大盘/市场整体 | L1 + L2 + L4 + L6 |
| 行业/板块 | L1(相关部分)+ L2(该行业政策)+ L3 + L4(该板块资金/情绪)+ L6 |
| 具体个股 | L1-L5全部 + L6;L1/L2若已有大盘层级结论可直接引用 |
| 已持仓组合 | 组合内每只股票分别跑L5,再叠加组合层面集中度/相关性(见L6) |

提问模糊(如"最近风险大不大")默认按"大盘整体";给了具体股票代码/名称按"具体个股"展开到L5;拿不准时一句话跟用户确认,不要自行猜测后跑错层级。

**本地输入**:持仓从 `../../../data/positions.json` 读、自选股从 `../../../data/watchlist.json` 读;文件不存在时提示用户先用对应skill/template建立,不凭空编造。

### 0.2 读取该对象未解除的红旗信号

读 `../../../data/risk_flags.json`(文件不存在时跳过,不阻塞,但需在报告中说明"无记忆状态,可靠性受限")。筛选 `object` 等于本次分析对象(个股用标准代码如 `600519SH`、大盘用 `大盘`、板块用 `板块:新能源`、组合用 `组合`)且 `status=open` 的红旗,作为本次的**必查项**——在 L5.5 阶段必须逐条重新核实:

- **仍存在**:报告"红旗清单"中保留,更新 `last_checked`;事件有进展(诉讼开庭、调查结论)需更新 `summary`,旧值追加进 `history`。
- **已解除**:报告中说明"原 XX 红旗已解除(依据:...)";回写时置 `status=resolved`、填 `resolution_date` 与 `resolution_note`,不删除条目(留痕)。
- **降级但仍需观察**(如ST摘帽但仍有未决诉讼):置 `status=downgraded`,后续按 open 处理。

**未读取或读取失败时不得假设"无历史红旗"**,需如实说明。

### 0.3 取数计划

取数桶路由与 gate 流程由 `review-orchestrator` 在调用本技能前已完成,详见 `../../../references/data-source-priority.md`,本技能不重复。取数过程中记录每类数据实际走的工具(primary 还是 fallback),供末尾"数据来源"小节使用。

## 六层风险框架

完整的检索字段清单、判断阈值、红旗信号表见 `references/risk_dimensions.md`——首次使用或不确定某层具体要查什么字段、什么数值算高风险时,务必先读那个文件。下面是每层的概览。

### 全球维度横切(各层都需叠加)

全球/海外维度散落在 L1/L2/L3/L4/L5.5,为避免每层重复展开,集中在此查阅,各层只叠加不重述:

- **全球宏观外溢(L1)**:主要央行同步收紧(加息+缩表)压制全球风险偏好;DXY 与美债收益率同步上行压制 A 股成长股估值与北向资金;中美 10 年期利差深度倒挂(美债高于中债 100bp 以上)提示人民币贬值与资本外流;原油/铜异动是全球需求或地缘风险领先信号;多区域地缘风险共振(俄乌+中东+中美等)需上调系统性风险等级。
- **海外政策外溢(L2)**:美国关税/出口管制/对华投资限制、欧盟碳关税与产业政策、海外上市审计与退市规则、主要贸易伙伴反倾销调查。结合分析对象海外营收占比与产业链位置判断传导强度——终端市场在限制清单内的为直接冲击,仅上游原料/中游代工环节暴露的为间接传导但有定价权侵蚀。
- **海外行业敞口(L3)**:海外营收占比超过 30% 且主要目的地出现关税/管制/反倾销政策时,单列外溢风险;全球产能同步扩张(新能源/光伏/电动车链条历史案例)即使国内格局稳定,也面临海外价格战与产能出清风险。
- **全球风险偏好与跨资产联动(L4)**:VIX 飙升至 20 以上且持续高位,往往伴随全球风险资产共振回调;中美利差深度倒挂叠加美元走强,是外资减持 A 股的典型组合;A 股与标普 500/恒生指数相关性短期内急剧抬升,提示受全球系统性因子主导,国内政策对冲效果被削弱。
- **海外事件性红旗(L5.5)**:实体清单/SDN/出口管制名单、海外重大诉讼(专利/反垄断/集体诉讼/337 调查)、海外退市或审计争议(HFCAA/PCAOB)、反倾销/反补贴税——命中即一票否决,详见 L5.5。

### L1 宏观环境风险

查国内 GDP/PMI/社零/工业增加值、MLF/LPR、社融 vs 名义 GDP、M1-M2 剪刀差、汇率与北向资金、CPI/PPI、地产销售;叠加全球维度横切。关键阈值:PPI 连续 6 个月以上负增长、地产销售连续两位数下滑、北向资金连续 2-3 个月净流出均为风险信号。输出:宏观风险等级 + 国内经济周期阶段(扩张/复苏/滞胀/衰退)+ 全球外溢方向(正/中/负+传导渠道)+ 未来 1-3 个月跟踪日历。

### L2 政策与制度风险(A股特有)

查 IPO/再融资节奏、退市新规执行、注册制细则、监管机构表态、所在行业专项整治、交易规则变动;叠加海外政策外溢。红旗信号:1-2 个月内同一行业连续 2 次以上监管发文或处罚、交易规则非常规临时性调整、头部公司被立案调查(行业性收紧先兆)。输出:政策风险等级 + 近 3-6 个月政策事件时间线(附日期)+ 未来催化剂 + 海外政策外溢提示(如适用)。

### L3 中观行业/板块风险

查行业生命周期阶段、集中度、供需/库存周期、产能利用率、行业估值历史分位(>80% 警惕过高,<20% 结合基本面判断预期差)、技术替代、政策依赖度;叠加海外行业敞口。输出:行业风险等级 + 估值历史分位区间 + 1-3 条核心风险点 + 海外敞口提示(如适用)。

### L4 市场交易结构与情绪风险

查全市场 PE/PB 历史分位、融资融券余额变化、北向资金短期流向、新发基金规模、涨跌停家数比、市场换手率、量化交易占比;叠加全球风险偏好。红旗信号:融资余额快速攀升 + 涨跌停家数比严重失衡 + 换手率历史高位三者同时出现,是情绪过热、后续回调风险上升的组合。输出:市场情绪风险等级 + 情绪周期定性(冰点/修复/亢奋/退潮)+ 短期流动性风险提示 + 全球传导方向(如适用)。

### L5 微观个股风险(仅当分析对象为具体个股/持仓组合中的个股时展开)

拆成六个子块,完整字段与阈值在 `references/risk_dimensions.md`:

- **5.1 财务**:资产负债率、有息负债、流动/速动比率、经营性现金流 vs 净利润(连续 2 年为负但净利润为正="纸面富贵"重大红旗)、应收/存货增速 vs 营收、商誉占净资产(>30% 警惕减值)。
- **5.2 公司治理**:前十大股东股权质押(控股股东>50% 叠加股价下跌警惕平仓)、限售股解禁时间表、实控人/高管近 6 个月增减持、审计意见(非标=重大红旗,必须单独 highlight)、关联交易占比。
- **5.3 经营**:前五大客户/供应商集中度、主营增速 vs 行业、政府补贴占净利润比例、管理层非正常变动、海外业务敞口(海外营收占比/汇率敞口/跨境供应链关键环节)。
- **5.4 估值**:PE/PB/PEG 相对自身历史分位与行业分位(>80% 警惕透支)、近期涨幅 vs 基本面变化(题材炒作特征)。
- **5.5 特殊/事件性(一票否决)**:ST/\*ST、未决重大诉讼、监管立案调查/行政处罚、股权冻结、重大舆情、海外制裁/实体清单/出口管制、海外重大诉讼、海外退市/审计争议、反倾销/反补贴税。**命中任一,不论其他层面多好看,总体结论都必须标注"高风险/需谨慎",不能被平均掉。**
- **5.6 技术面(辅助)**:优先复用 `ashare-technical-analysis` 打分结果;无则只做粗略定性(放量下跌/跌破关键均线等)并注明简化,不重算指标,不单独决定整体结论。

输出:六个子块各自的风险等级 + 具体异常项列表(哪个科目/哪个指标异常,不要只给"财务风险:中"这种无信息量结论)。

### L6 风险综合与分类输出

把 L1-L5 识别的风险点归类为:
- **系统性风险**:无法通过精选个股规避,只能靠仓位管理/对冲应对(L1/L2/L4 + 全球系统性外溢)。
- **非系统性风险**:可通过分散持仓、精选标的降低(主要来自 L5 个股自身,含个股层面海外业务/汇率/制裁敞口)。

**总体风险等级遵循"红旗信号优先于加权平均"**:L5.5 命中任何红旗,总体直接标"高/需谨慎",跳过加权,在报告中醒目单独列出,不能被其他维度分数平均掉。

**全球系统性风险叠加规则**:L1(全球宏观)+ L2(海外政策外溢)+ L4(全球风险偏好)三层全球维度同时出现"高"信号(典型:主要央行同步收紧 + 美元与美债收益率同步上行 + VIX>20),即使国内层面仅"中",总体上调一档(中→中高,中高→高),并在报告中指出这是全球系统性因子主导、国内政策对冲空间受限。单层全球维度为高、其他不共振时不上调,但标注"需重点跟踪是否演化为全球共振"。

**持仓组合额外检查**:统计组合内个股在行业/风险因子上的集中度,过度集中在同一受政策/周期影响的行业,即使单只个股风险不高,组合层面风险也可能被低估——这是 L6 延伸判断,不是重新计算个股等级。

**区分结构性风险与事件性风险**:结构性是慢变量(行业生命周期、全球产业链重构),不会因一两天没新消息而改变;事件性必须标注具体日期,避免把过时旧闻当新催化剂。

## 撰写最终报告

按 `references/report_template.md` 的固定结构输出,核心是:分层风险速览表(一眼看出哪层风险高)+ 分层详细说明 + 红旗信号清单(如有,置顶)+ 数据来源与缺口说明 + 风险提示与免责声明。不要把六层检索字段原样罗列成流水账,要对每层给出有判断力的文字结论,各层结论互相矛盾时明说矛盾本身,不和稀泥。

## 输出与回写

### 报告落盘

完成报告后,除对话展示外,把完整报告保存到 `../../../output/ashare-risk-assessment/`:

- 个股:`<标准代码>_risk_[日期].md`(如 `600519SH_risk_2026-07-01.md`)
- 大盘/板块/组合:`risk_<对象简述>_[日期].md`(如 `risk_大盘_2026-07-01.md`、`risk_持仓组合_2026-07-01.md`)

日期格式 `YYYY-MM-DD`。文件夹不存在则创建,同名文件已存在直接覆盖。

### 红旗跟踪表回写

报告落盘后,更新 `../../../data/risk_flags.json`(文件不存在时以 `../../../templates/risk_flags_template.json` 为骨架新建)。本skill是该文件唯一写入者。按以下顺序处理:

1. **核对步骤0.2读出的 open 红旗**(逐项判断本次结果):仍存在→更新 `last_checked`/`last_report_date`;`summary` 有变化则旧值追加进 `history` 后覆盖写新值,`status` 保持 `open`。已解除→置 `status=resolved`、填 `resolution_date` 与 `resolution_note`,不删除。降级→置 `status=downgraded`,填 `resolution_note`,后续按 open 处理。
2. **追加本次新发现红旗**:L5.5 命中、但步骤0.2读出清单中没有的,按模板字段新增(`first_noted`/`last_checked`/`last_report_date` 均填本次日期,`status=open`,`source_report` 填刚落盘的报告路径)。
3. **不写入非红旗内容**:L1-L4 系统性风险等级、L5.1-5.4 非红旗异常项、估值分位、情绪周期等不写入本文件——本文件只跟踪"一票否决级红旗",不是风险报告镜像。
4. **保存后输出一行摘要**:本次新增 X / 仍存在 Y / 解除 Z / 降级 W,不把整个 JSON 贴出来。

回写是"事实记录"不是"重新判断"——不要在回写阶段修改本次报告已给出的风险等级结论,也不要把非红旗观察项硬塞进来稀释其作为"必查清单"的价值。
