# A股复盘助手

基于 Claude Code 技能体系构建的 A 股复盘辅助系统。覆盖"盘前→盘中→盘后→周末"完整周期，维护本地宏观记忆，结合持仓/自选股/板块，提供贯穿交易日的纪律核对与信息汇总。

## 这套系统能做什么

- **全天候信息闭环**：盘前隔夜外盘汇总 → 盘中 15 分钟快速纪律核对 → 盘后深度复盘 → 周日清算积压事项，四个时间窗技能首尾衔接，"待观察事项"在彼此间交棒
- **个股技术面深度分析**：点名任意个股即给出均线/MACD/RSI/KDJ/布林带/ADX/量能/支撑阻力位多维指标，五维度加权打分及买卖/止损止盈参考区间
- **全维度投资风险排查**：宏观/制度/行业/市场/微观六层风险框架，红旗信号一票否决优先于加权打分；按需触发，或由复盘技能命中风险信号时自动接力、周复盘前自动预跑
- **三时间框架机会发掘**：日内（量比异动/板块共振）、短期（政策/消息催化）、中长期（主行情新方向），催化剂驱动与基本面分栏呈现，不混用判断标准
- **宏观环境记忆**：13 维度（政治/经济/货币/财政/汇率/地产/通胀/人口/国际/制度/央行/会议日历/产业热点）分层维护，慢变量 90 天、周期变量 30 天、事件驱动即时更新
- **持仓纪律核对**：以投资逻辑是否实质变化为持有/卖出依据，短期消息/技术信号只标记观察，不单独驱动买卖
- **自动接力与定时推送**：编排 Agent 自动消费宏观队列、风险接力、生成移动端数据看板；`scheduler/run_review.py` 按交易日历无头调用 Claude Code，SMTP 推送报告到邮箱
- **移动端数据看板**：复盘报告自动渲染为深色单栏 HTML，单文件自包含可离线打开，适合手机阅读

## 核心思想

- **持股纪律**：以投资逻辑（thesis）是否发生实质变化为持有/卖出判断依据。短期消息/技术信号只能标记观察，不能单独驱动买卖
- **不预测、只描述**：输出"发现了什么、有什么待办"，不预测走势、不给投资建议
- **短/中长期分栏**：催化剂驱动与基本面驱动分开呈现，不混用判断标准
- **宏观只做校准**：宏观背景用于解释现象和环境校准，不反向驱动个股买卖结论

完整边界见 `references/boundaries.md`（§1-§8 固定编号，供各技能按号引用）。

## 24 小时信息闭环

| 时段 | 技能 | 做什么 |
|------|------|--------|
| 08:00–09:15 盘前 | `ashare-morning-brief` | 隔夜美股/欧洲/全球汇总，核对隔夜观察事项，产出今日观察清单 |
| 14:20–15:00 盘中 | `ashare-intraday-review` | 15 分钟快速检查：大盘/资金流向/板块温度计、短期机会发掘（独立技能，不与其他复盘技能关联） |
| 17:00–23:30 盘后 | `ashare-evening-review` | A 股全天+亚太收盘复盘，白天消息面整理，**唯一全量跑技术引擎的时段**，产出隔夜观察事项交棒 |
| 周日 09:00–12:00 | `ashare-weekly-review` | 周度深度复盘：大盘/持仓/板块/未结事项清算，下周事件预告 |

早间、晚间、周复盘三个技能首尾衔接，通过“待观察事项”在彼此间交棒。周复盘清算本周积压事项，产出下周预告作为新一周的起点。盘中复盘为独立技能，不参与交棒链。

此外，编排层在复盘命中风险信号（如一票否决级红旗苗头）时自动接力 `ashare-risk-assessment` 对相关标的深挖，并在周复盘前先跑一次组合风险预跑（详见下文「自动接力机制」）。

## 技能一览

### 时间窗复盘（主线）

| 技能 | 触发方式 | 职责 |
|------|----------|------|
| `ashare-morning-brief` | 时间窗 / 手动 | 盘前隔夜推送：美股/欧洲行情、隔夜消息四类分组、今日技术参考位承接、今日观察清单 |
| `ashare-intraday-review` | 时间窗 / 手动 | 盘中独立快照：大盘/资金流向/板块温度计、短期机会发掘（不读写持仓/自选股/宏观记忆，不与其他复盘技能关联） |
| `ashare-evening-review` | 时间窗 / 手动 | 盘后深度复盘：A 股全天+亚太、白天消息面、板块轮动持续性、持仓/自选股四维深度卡片（技术面/资金面/消息面/相对强弱） |
| `ashare-weekly-review` | 时间窗 / 手动 | 周度深度复盘：中期均线趋势体检（ma60/120/250）、alpha/beta 坐实、VIX 周度趋势、板块周度轮动持续性、下周事件预告 |

### 分析/发现

| 技能 | 触发方式 | 职责 |
|------|----------|------|
| `ashare-opportunity-discovery` | 复盘技能调用 / 手动 | 三时间框架机会发掘：`intraday`（量比异动/板块共振）、`short_term`（政策/消息催化/跨市场传导）、`medium_term`（主行情新细分方向/跨日题材演化）。与持仓基本面分栏呈现 |
| `ashare-technical-analysis` | 用户点名个股 | 纯技术面分析：均线/MACD/RSI/KDJ/布林带/ADX/量能/ATR/支撑阻力位等多维指标，五维度加权打分，给出买入/持有/减仓/卖出/观望结论及止损止盈参考区间 |
| `ashare-risk-assessment` | 用户点名 / 风险接力 / 周复盘预跑 | 全维度投资风险排查：宏观/制度/行业/市场/微观六层框架（每层定义检索字段、判断阈值、红旗信号），红旗一票否决优先于加权打分，产出分层风险清单与总体风险等级 |

### 基础设施

| 技能 | 触发方式 | 职责 |
|------|----------|------|
| `ashare-macro-context` | 手动 / 自动接力 | 13 维度宏观记忆维护，两种模式：**完整维护**（全量 8 步：消费队列 + tier 复核 + 到期检查 + candidate 转正/淘汰）和**队列消费**（只落库新事件，日常复盘后自动接力） |
| `ashare-dashboard` | 自动接力 / 手动 | 复盘报告 → 移动端数据看板 HTML。动态匹配模板，深色单栏布局，单文件自包含可离线打开 |
| `ashare-data-source-config` | 手动 / 自动接力 | 探测本地可用的金融数据工具，编排出"数据类型→具体工具链"的优先级配置并写入长期记忆，供所有技能取数前读取 |

### 自动接力机制（编排 Agent 负责）

- **日常接力**（morning/intraday/evening 后）：只跑队列消费——快速落库新 Tier 3 事件，不触发全量 tier 复核
- **周复盘接力**：跑完整维护——消费队列 + 全量 tier 复核 + 到期检查 + candidate 转正/淘汰
- **看板接力**：调度器要求时，复盘后自动渲染移动端数据看板 HTML
- **风险接力**：① 复盘命中风险信号（一票否决级红旗苗头/重大异动/重大公告）时，自动接力 `ashare-risk-assessment` 对相关标的深挖；② 周复盘前先跑一次组合风险预跑（L6 集中度 + 变化标的 L5），周复盘保持独立、不受影响

## 宏观记忆体系

13 维框架（A-M），按变化节奏分三层复核：

| Tier | 类别示例 | 复核周期 |
|------|----------|----------|
| **Tier 1 慢变量** | 政治与政策、人口结构、国际形势、资本市场制度、长期产业热点 | 90 天 |
| **Tier 2 周期变量** | 宏观经济、货币流动性、汇率、房地产、通胀大宗商品 | 30 天 / 月度数据 |
| **Tier 3 事件驱动** | 重要会议日历、全球央行政策、突发政策/事件 | 即时更新 |

**维度扩展机制**：新因素默认收敛到现有类别子项 → 无法归入时进入 `candidates` 缓冲观察（1-2 个 tier-2 周期）→ 持续活跃且无法被覆盖才升级为正式顶层类别。

**单一写入者**：`data/macro_context.json` 的唯一写入者是 `ashare-macro-context`。日常复盘技能发现 Tier 3 事件时，只追加到 `data/macro_updates_queue.json`，由编排 Agent 自动接力消费队列完成落库。

## 技术面深度体系

三个复盘技能各自内联技术深度配方（引擎调用方法、字段口径、四维卡片写法、降级规则均已写入各自 SKILL.md）：

- **晚间复盘**（唯一全量跑技术引擎的时段）：大盘四大指数 + 全部持仓/自选股，产出四维深度卡片
- **早间推送**（不现算）：承接昨晚技术参考位，只做隔夜外盘定性
- **周复盘**（中期视角，独立跑引擎）：关注 ma60/120/250 中期均线、alpha_20d/60d 相对强弱、周度量价
- **技术指标计算**：`compute_indicators.py` + `score.py`（五维度加权打分），降级规则严格如实声明缺失维度，绝不编造数字

> 注：`ashare-intraday-review` 已精简为独立技能（大盘/资金流向/板块温度计 + 短期机会发掘），不再引用技术深度指南、不承接昨晚技术参考位。

## 定时调度 & 邮件推送

`scheduler/run_review.py` 被 cron/任务计划按固定时刻拉起：

1. 按当前时间命中时间窗 → 选出对应技能
2. 判断当天是否 A 股交易日（按工作日判断，排除周六周日）
3. 无头调用 Claude Code 执行技能
4. 通过 SMTP 发送报告到配置邮箱
5. 可选：自动生成数据看板 HTML 作为邮件正文（若当日触发风险接力/周预跑，看板邮件末尾自动追加「风险识别」板块，内容取自 `output/ashare-risk-assessment/`）

```bash
python scheduler/run_review.py                       # 按当前时间自动选技能
python scheduler/run_review.py --skill ashare-evening-review  # 强制指定技能
python scheduler/run_review.py --dry-run             # 调试：只判断不执行
```

配置 `scheduler/config.yaml`（从 `config.example.yaml` 复制）：

```yaml
dashboard:
  enabled: true    # 是否生成数据看板 HTML（关闭则发纯文本）
email:
  enabled: true    # 是否发送邮件
```
